# Legend of Monster（コードネーム）

サイバーパンク都市を舞台にした、ブラウザで遊べる見下ろし視点の2Dハクスラ×ローグライク（ローグライト）アクションです。
身内で遊ぶ非商用の趣味の作品で、大学での個人開発の実績でもあります。

- 企画・仕様・テストプレイ：村田
- 実装：Claude Code（Anthropic の AI コーディングツール）

## どんなゲームか

依頼を受けた「ハンター」になって、暴走した生体兵器が棲みつく区画へ潜ります。

- **1回の挑戦（ラン）は約15分**。3つのエリア（下層スラム → 冷却プラント → 企業タワー）を進み、それぞれの最後にボスがいます
- **道は毎回変わります**。エリアごとに枝分かれした地図が作られ、進む部屋を自分で選びます
- **ハクスラ**：敵が落とす装備（レア度4段階）と、レベルアップで選ぶインプラントで、ランごとに違う強くなり方をします
- **ローグライト**：死ぬとラン中の装備やレベルは失いますが、ボス素材は持ち帰れます。隠れ家で恒久強化や武器の解放に使えます
- 武器は3種類：大剣（重い一撃と溜め斬り）、片手剣（手数とジャストガード）、銃（遠距離と拡散射撃）

## 操作

| 操作 | 動作 |
|---|---|
| WASD（矢印キーでも可） | 移動 |
| マウス | カーソルの方向を向く。攻撃もその方向に出る |
| 左クリック | 攻撃（大剣は長押しで溜め斬り、銃は押している間ずっと撃つ） |
| 右クリック | 特殊アクション（片手剣：ジャストガード／銃：拡散射撃／大剣：奥義） |
| Shift | ダッシュ回避（無敵時間あり） |
| E | 調べる・落ちている装備を身につける・扉を選ぶ |
| F | 落ちている装備を、身につけずにバッグに入れる |
| Q | 修復キットを使う |
| 1・2 | 消耗品を使う（レベルアップの3択が出ているときは、1・2・3 で選ぶ） |
| M | エリアの地図 |
| Esc / Tab | ポーズ画面（ステータス、装備の付け替え、地図、記録、データ片、実績、操作説明、設定） |

PC のキーボードとマウスで遊んでください（ゲームパッドとスマホには対応していません）。
セーブデータはブラウザに自動で保存されます（セーブ枠は3つ）。保存されるのは隠れ家の進行状況だけで、ランの途中は保存されません。
音量、表示の大きさ、画質、フルスクリーンは、ポーズ画面か隠れ家のメニューの「設定」で変えられます。

## 手元で動かす

[Node.js](https://nodejs.org/) が必要です。

```bash
npm install
```

```bash
npm run dev
```

表示された URL（例：`http://localhost:5173`）をブラウザで開きます。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用に起動する（確認用のキーが使える） |
| `npm test` | ゲームのルールの自動テストを実行する |
| `npm run build` | 公開用のファイルを `dist/` に作る |

`main` ブランチに push すると、GitHub Actions がテストとビルドを行い、GitHub Pages に公開します（`.github/workflows/deploy.yml`）。

## フォルダの見方

| 場所 | 中身 |
|---|---|
| `docs/` | 企画書・詳細仕様・実装計画（仕様の正本） |
| `src/data/` | 定義データ。敵、ボス、武器、装備の効果、インプラント、消耗品、部屋、エリア、恒久強化、実績、文章、音、調整用の数値 |
| `src/logic/` | ルールの計算（ダメージ、ドロップ抽選、地図の生成、セーブデータなど） |
| `src/game/` | 戦闘の進行（プレイヤー、敵、ボス、効果の仕組み） |
| `src/render/` | 描画（コードで描くネオン線画） |
| `src/scenes/` | 画面（タイトル、隠れ家、戦闘、エンディング、ポーズ画面） |
| `src/audio/` | 音を鳴らす仕組み |
| `tests/` | 自動テスト |

新しい敵・装備の効果・インプラント・実績などは、原則として `src/data/` に1件足すだけで増やせる作りにしています。
調整用の数値は `src/data/balance.js` と、それぞれの定義データに集めてあります。

## AI を使った部分

実績として説明できるように、AI を使った部分を明記します。

- **プログラム**：すべて Claude Code が書きました。企画・仕様・遊んでの判断と調整の指示は村田が行っています
- **ゲーム内の文章**（依頼文、通信ログ、データ片、エンディング、実績の名前）：Claude Code の下書きを元にしています
- **絵**：画像素材は使っていません。キャラクター、敵、エフェクト、アイコン、背景、UI はすべてコードで描いています
- **音**：音声ファイルは使っていません。効果音も BGM も、ブラウザの Web Audio でその場で合成しています（曲のデータは `src/data/audio.js`）

外部の素材（フォントなど）は [CREDITS.md](CREDITS.md) に記録しています。既存の作品・キャラクター・作家に似せた素材は作っていません。
