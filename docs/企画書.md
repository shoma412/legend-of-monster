# Legend of Monster（コードネーム） 企画書 v0.4

## 1. 目的とゴール
- **一言で**：サイバーパンク都市を舞台にした、ブラウザで遊べる見下ろし視点の**ハクスラ×ローグライク**アクション
- **目的**：趣味として楽しく作ること＋大学での個人開発実績（企画・仕様・テストは自分、実装はClaude Code）
- **このプロジェクトでやること**：企画・詳細仕様の確定と、本実装用の引き継ぎ資料の作成（＋雰囲気確認用の試作版）
- **完成の条件**：URLを開けば誰でも遊べ、最深部のボスを倒すとエンディングが見られる

## 2. 世界観
ネオン輝く巨大都市の地下や廃区画に、企業の実験で生まれた暴走生体兵器（サイバーモンスター）が棲みついている。
主人公は依頼を受けて地下へ潜る「ハンター」。潜るたびに区画の構造は変わり、倒した敵から装備とパーツを回収して強くなっていく。

## 3. ゲームの流れ
```
隠れ家（拠点）
  └ 出撃（1回の挑戦＝ラン）
       エリア1（数部屋）→ ボス1
       エリア2（数部屋）→ ボス2
       エリア3（数部屋）→ ボス3（ラスボス）
  └ 死亡 or クリアで隠れ家へ戻る → 持ち帰ったものでずっと残る強化 → 再出撃
```
- **ハクスラ要素**：雑魚を大量になぎ倒す爽快感。敵はランダムな性能の装備を落とす（レア度＋ランダム効果）
- **ローグライク要素**：部屋の並び・敵・報酬が毎回ランダム。死ぬとラン中の装備は失う。レベルアップ時の3択強化でランごとにビルドが変わる
- **長期の成長（ローグライト要素）**：ボスのパーツなど一部だけ持ち帰り、隠れ家で恒久強化や武器の解放に使う

## 4. 最初の版（MVP）に入れるもの
| 項目 | 内容 |
|---|---|
| 操作 | キーボードのみ。WASD移動、ダッシュ回避、攻撃、特殊攻撃 |
| 武器 | 3種：**大剣**（重い一撃・範囲）、**片手剣**（手数・素早い）、**弓**（遠距離） |
| 装備ドロップ | 武器・防具・アクセサリー。レア度4段階（コモン／レア／エピック／レジェンド）、レア度が高いほどランダム効果が多い |
| ラン中の強化 | レベルアップ時に「インプラント」3つから1つ選ぶ（例：ダッシュ後3秒攻撃力+30%、撃破時に電撃連鎖） |
| 敵 | 雑魚3〜4種＋ボス3体。属性は電撃／熱／冷却 |
| マップ | 部屋をつないだ構成。エリアごとに部屋の並びをランダム生成 |
| 隠れ家 | 出撃、恒久強化、武器の解放だけ |
| 保存 | 隠れ家の進行状況をブラウザに自動保存（ラン途中の保存はしない） |

## 5. ボス案（仮）
1. **ボルトボア**：電線を食い荒らす機械猪。突進と放電の踏みつけ。弱点＝冷却
2. **クライオ・ワイバーン**：冷却装置を背負った飛竜型ドローン。冷気ブレスと尻尾。弱点＝熱
3. **オーバーロード**：暴走した企業の最終兵器。範囲攻撃とオーバーヒート状態。弱点＝電撃

## 6. 作る順番（本実装向け）
1. 大剣＋雑魚＋ボルトボアで、1エリアが遊べる状態
2. 装備ドロップとインプラント選択を追加し、ハクスラの手触りを作る
3. 部屋のランダム生成と、死亡→隠れ家→再出撃のループ
4. 片手剣・弓、エリア2・3とボス2体、エンディング
5. 見た目・音・バランス調整をして公開

## 9. 決定済み
- 武器3種（大剣・片手剣・弓）／コードネーム Legend of Monster／世界観サイバーパンク／操作はキーボードのみ／ハクスラ×ローグライク
- 死亡時：ラン中の装備・レベル・インプラントは失う。**ボス素材だけ持ち帰り**、隠れ家で恒久強化に使う（ローグライト）
- 1回のランは**約15分**（3エリア×各約5分。1エリア＝雑魚部屋3〜4つ＋ボス部屋）
- マップは**部屋をつなぐ形**。エリアごとに部屋の並びをランダム生成
- 武器は**出撃前に1つ選ぶ**。ラン中は持ち替えない（ドロップする武器モッドは選んだ武器を強化する）

## 10. 素材（絵・SE・BGM）の入手方針（案）
オリジナリティを出すため「方向性と最終判断は自分、作業はAIとコード」を基本にする。

| 種類 | 手段（案） | 注意点 |
|---|---|---|
| ゲーム中の絵（キャラ・敵・エフェクト・UI） | **コードで描くネオン線画**（試作版の方式）を基本にする | 外部素材を使わないので権利の心配がない。見た目の統一もしやすい |
| タイトル画面・ボスのキービジュアル | 画像生成AIで作り、自分で選別・加工する | 利用規約で商用可否を確認。既存作品名や作家名をプロンプトに入れない |
| SE | コードで合成（Web Audio）＋必要なら効果音生成AI | ElevenLabsの無料プランは商用ライセンスなし（有料のStarterから付与） |
| BGM | 音楽生成AI（例：Suno） | Sunoの無料プランは「個人的・非商用」のみで所有権はSuno側。商用利用はPro/Premierで、2026年9月3日施行の規約では加入中に正規ダウンロードした曲に限られる |

共通ルール：
- 使った素材は「ツール名・プラン・日付・プロンプト」を一覧（CREDITS.md）に記録する
- 既存の作品・キャラ・作家に似せる指示はしない（日本では既存作品との類似性と依拠性があれば侵害になりうる：文化庁「AIと著作権に関する考え方について」2024年3月）
- READMEにAIを使った部分を明記する（実績として説明するときにも役立つ）

**決定（2026-10-03）**：基本は身内で遊ぶ非商用なので、**無料プランで作る**。
ただし無料プランのSuno曲は所有権がSuno側で、あとから商用にはできない。もし販売・収益化することになったら、BGMは有料プランで作り直すか別の曲に差し替える。そのためBGMは後から差し替えやすい作りにしておく。
