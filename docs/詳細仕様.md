# Legend of Monster 詳細仕様 v0.1（案）

企画書（[企画書.md](企画書.md)）で決めた骨組みを、実装できる粒度まで具体化したもの。数値はすべて初期値で、遊びながら調整する前提。

---

## 1. ラン（1回の挑戦）の構成：約15分

| エリア | 舞台 | 部屋の構成 | ボス |
|---|---|---|---|
| 1 | 下層スラム（電線とネオン看板の路地） | 最初の戦闘部屋 ＋ 途中3部屋（道によって変わる）＋ ボス | ボルトボア |
| 2 | 冷却プラント（凍った配管と蒸気） | 最初の戦闘部屋 ＋ 途中3部屋（道によって変わる）＋ ボス | クライオ・ワイバーン |
| 3 | 企業タワー最深部（サーバールーム） | 最初の戦闘部屋 ＋ 途中3部屋（道によって変わる）＋ ボス | オーバーロード |

- 1エリアの目安は約5分（戦闘部屋1つ40〜60秒、ボス戦1.5〜2分）
- **分かれ道**：エリアに入った時点で、枝分かれした地図を作る（2026-10-04 変更）。部屋をクリアすると、地図の線でつながった部屋への扉が1〜2つ開き、扉の上に「次の部屋の種類」がアイコンで出る。どちらに進むかをプレイヤーが選ぶ
- **エリアの地図**：左から右へ「最初の戦闘部屋 → 途中の3列（上下2部屋ずつ）→ ボス」。各部屋から次の列の1〜2部屋へ線が伸び、線でつながった部屋にだけ進める。どの道でも通る部屋は5部屋
- 画面右上に小さい地図を常に出し、M キーで大きい地図を出す（戦闘は止めない）。通った部屋、今いる部屋、進める道、もう行けない部屋が分かる
- エリアの最後は必ずボス部屋。ボスを倒すと全回復して次のエリアへ

### 部屋の種類
| 種類 | 内容 |
|---|---|
| 戦闘 | 雑魚の波（2〜3波）。クリアで経験値・クレジット・装備ドロップ |
| エリート | 強化個体1体＋取り巻き。報酬はレア以上の装備が確定 |
| 補給 | 戦闘なし。HPを40%回復 |
| 闇市 | クレジットで装備・修復キット・インプラントを買う |
| データ金庫 | 戦闘なし。装備3つから1つ選んで持っていく |

途中の6部屋（3列×上下）の中身は抽選で決まる。エリアごとに「エリート1〜2つ、特殊部屋2つ（補給・闇市・データ金庫のうち別々の種類）、残りは戦闘」が入り、同じ列の上下は違う種類になる。道によって通る部屋が変わるので、エリート2連戦の道も、エリートなしの道もありうる。

- 最初の部屋は必ず戦闘部屋
- 戦闘のない部屋（補給・闇市・データ金庫）は、入った時点で扉が開いている。データ金庫は何も取らずに進んでもよい
- 闇市・データ金庫で手に入れた装備はその場で身につけ、外した装備は足元に落ちる

## 2. 持ち帰り（ローグライト要素）

| 区分 | 中身 | 死んだとき |
|---|---|---|
| ラン中だけのもの | レベル、インプラント、装備、クレジット、修復キット | すべて失う |
| 持ち帰るもの | **ボス素材**（ボアコア／クライオコア／オーバーコア） | 倒したボスの分だけ残る |
| 持ち帰るもの | **データ片**（企業の実験記録の断片。「11. 世界観の見せ方」） | 拾った時点で残る |
| 持ち帰るもの | **実績**（「12. 実績」） | 解除した時点で残る |

- ボス素材はボスを倒した時点で確定する（その後で死んでも失わない）
- 1体につき1個。初回撃破だけ3個もらえる（序盤の強化を早めるため）

## 4. 操作

| キー | 動作 |
|---|---|
| WASD | 移動 |
| マウス | カーソルの方向を向く |
| 左クリック | 攻撃 |
| 左クリック長押し | 溜め攻撃（大剣の溜め斬り。クールダウン制） |
| 右クリック | 未定（後で決める） |
| Shift | ダッシュ回避（無敵時間あり） |
| Q | 修復キットを使う（HP 35回復） |
| E | 扉を選ぶ・闇市で買う・装備を拾う |
| M | エリアの地図（もう一度押すと閉じる） |
| Tab | ステータス画面（装備とインプラントの一覧） |
| Esc | 一時停止 |

攻撃の向きはマウスカーソルの方向。片手剣・銃の特殊攻撃の操作と、銃の自動照準（正面寄りにいる一番近い敵を狙う）を入れるかは M6 で決める。

## 5. 武器

| 武器 | 通常攻撃（左クリック） | 特殊攻撃（大剣は左クリック長押し。片手剣・銃は未定） | 特徴 |
|---|---|---|---|
| 大剣 | 遅い3段斬り。最初は角度が狭く（約45度、3段目は約90度）、インプラントで広げられる。振っている間は移動が遅い | **溜め斬り**：長押しで3段階まで溜め、最大で威力3倍 | 一撃が重い。雑魚の群れをまとめて吹き飛ばす |
| 片手剣 | 速い4段コンボ。4段目だけ威力1.5倍 | **ジャストガード**：0.3秒だけ構え、攻撃を受けると無効化して反撃 | 手数と操作のうまさで戦う |
| 銃 | 弾を連射 | **拡散射撃**：5方向に同時に撃つ | 距離を取って安全に戦う。近づかれると弱い |

## 6. 装備（ハクスラ要素）

- スロットは3つ：**武器モッド**（選んだ武器を強化）、**防具**、**アクセ**
- レア度：コモン（白）／レア（水色）／エピック（紫）／レジェンド（金）。効果の数は1／2／3／4個
- レジェンドだけは、下の「固有効果」を1つ必ず持つ（効果4個のうち1つが固有効果、残り3つが通常の効果）

### 効果のプール
| 効果 | 範囲（レア度で上がる） |
|---|---|
| 攻撃力 +% | 5〜20% |
| 会心率 +% | 3〜12% |
| 会心ダメージ +% | 20〜60% |
| 攻撃速度 +% | 5〜15% |
| 最大HP + | 10〜40 |
| 移動速度 +% | 4〜12% |
| 被ダメージ −% | 3〜10% |
| 属性付与 | 電撃／熱／冷却のどれか |
| 撃破時HP回復 | 1〜4 |
| クレジット獲得 +% | 10〜30% |

### 属性と状態異常
- 属性は電撃／熱／冷却の3つ。装備の「属性付与」やインプラントで攻撃に付く。複数の属性を同時に持てる
- **熱属性**の攻撃は必ず「燃焼」（3秒間の継続ダメージ）を付ける
- **冷却属性**の攻撃は必ず「減速」（40%減速）を付ける
- **電撃属性**は、それだけでは状態異常を付けない（インプラント「過電流」で敵を止められる）
- インプラントの「焼却弾」「冷却コア」は、それぞれ熱属性・冷却属性を攻撃に付けるもの。装備の属性付与でも同じ状態異常が付く
- **ボス**への減速は半分の効き目（20%減速）。凍結と停止はボスには効かない

### レジェンドの固有効果（例）
| 名前 | 効果 |
|---|---|
| ゼロデイ | 会心が出ると次の攻撃も必ず会心（この効果で出た会心は、さらに次の「必ず会心」を呼ばない） |
| ネオン・ハロー | ダッシュした場所に3秒間ダメージ床を残す |
| ブラックアイス | 冷却状態の敵を倒すと周囲を凍らせる |
| オーバーフロー | HP満タンのとき攻撃力 +40% |

拾うときは今の装備との比較を表示し、Eで付け替える（自動では付け替えない）。

## 7. インプラント（レベルアップ時の3択）

レベルは毎ラン1から。1ランで Lv8〜10 くらいまで上がる想定。3系統に分けて、同じ系統を集めるほど強くなるようにする（ビルドの方向性を作るため）。

| 系統 | 名前 | 効果 |
|---|---|---|
| 電撃 | 連鎖放電 | 撃破時、近くの敵2体に電撃 |
| 電撃 | 過電流 | 電撃属性の攻撃が20%の確率で敵を0.5秒止める |
| 電撃 | 雷撃ダッシュ | ダッシュの通り道にいる敵に電撃ダメージ |
| 熱 | 焼却弾 | 攻撃に熱属性を付与し、3秒間の継続ダメージ |
| 熱 | 熱暴走 | HPが50%以下のとき攻撃力 +35% |
| 熱 | 爆炎処理 | 燃えている敵を倒すと小爆発 |
| 冷却 | 冷却コア | 攻撃に冷却属性を付与し、敵を40%減速 |
| 冷却 | 氷結装甲 | 被弾したとき周囲の敵を減速させる |
| 冷却 | 砕氷 | 減速中の敵への会心率 +25% |
| 汎用 | オーバークロック | 攻撃力 +20%（重ねがけ可） |
| 汎用 | 人工筋繊維 | 移動速度 +15%（重ねがけ可） |
| 汎用 | 装甲プレート | 最大HP +25、全回復（重ねがけ可） |
| 汎用 | アドレナリン回路 | ダッシュ後2秒間 攻撃力 +50% |
| 汎用 | 拡張ブレード | 近接範囲 +25%／弾が1体貫通 |
| 汎用 | 広角ブレード | 近接攻撃の角度 +50%（重ねがけ可。銃での効果は M6 で決める） |
| 汎用 | ナノ修復 | 撃破するたびHP +2 |
| 汎用 | 強欲プロトコル | クレジット獲得 +50%、被ダメージ +10% |

同じ系統のインプラントを3つ持つと「系統ボーナス」が発動する（電撃：連鎖数+2／熱：継続ダメージ2倍／冷却：減速した敵が凍結することがある）。

## 8. 敵

### 雑魚
| 名前 | 出るエリア | 動き |
|---|---|---|
| スカウトドローン | 1〜3 | 小さく速い。ふらつきながら突っ込んでくる |
| ストリートグラント | 1〜3 | 硬めの近接型。ゆっくり近づいて殴る |
| 監視タレット | 1〜3 | 距離を取って弾を撃つ |
| 自爆ボット | 2〜3 | 近くで1秒点滅してから爆発。範囲は床に表示 |
| フロストスプレイヤー | 2 | 冷気を前方に噴射。当たると減速 |
| シールド兵 | 3 | 正面からの攻撃を防ぐ。背後かダッシュで回り込む |
| スナイパー | 3 | 赤い照準線を出した後に高威力の一撃 |

### エリート
雑魚の強化版（グラントかタレットがなる）。HP3倍、色違い、攻撃されてもひるまない。下の特性から1つ付く：「分裂（倒すと小型2体）」「障壁（一定ダメージまで無効）」「加速（移動と攻撃が速い）」「吸収（周りの雑魚を回復）」。

### ボス
| ボス | 弱点 | 主な攻撃 | HPが半分を切ると |
|---|---|---|---|
| ボルトボア | 冷却 | 予告線つきの突進（壁に当たるとスタン）、放電の踏みつけ（衝撃波の輪） | 突進が2連続になる |
| クライオ・ワイバーン | 熱 | 空中からの冷気ブレス、尻尾なぎ払い、氷柱の雨（落下地点を表示） | 部屋の端から凍りつき、動ける範囲が狭まる |
| オーバーロード | 電撃 | レーザーの回転掃射、ドローン召喚、全体衝撃波 | オーバーヒート状態：攻撃が速くなるが、冷却中に数秒の大きな隙ができる |

## 11. 世界観の見せ方（2026-10-04 追加）

本格的なストーリーは入れず、短い文章と演出でサイバーパンクの雰囲気を出す。文章は Claude Code が下書きを出し、村田さんが最終判断する。既存の作品・キャラクターに似せない。

### 端末風の画面と言い回し
- 部屋に入ると区画名を表示する（例：「SECTOR 03 // 下層スラム」）
- ボス登場時に警告表示と異名を出す（例：「ボルトボア — 電線喰らい」）
- レベルアップ、装備の入手、死亡、クリアなどの表示を、ハッカー端末風の文体にそろえる

### 依頼と通信ログ
- 出撃前（隠れ家の出撃画面）に、依頼主からの短い依頼文を表示する
- ボスの前後に、1〜2行の通信が画面端に流れる。戦闘は止めない

### データ片
- 企業の実験記録の断片。集めるとボスの正体や企業の思惑が分かる
- 手に入る場所：ボス撃破時と、特殊部屋「データ金庫」
- 拾った時点で持ち帰りが確定し、死んでも失わない。隠れ家でまとめて読める。セーブデータに保存する
- 個数と本文は M5 で決める

## 12. 実績（2026-10-04 追加）

条件を達成すると解除される、普通のゲームの実績。

- 解除した実績は死んでも失わない。隠れ家の「実績の一覧」で見られる（未解除のものは条件だけ見える）。セーブデータに保存する
- 解除したときは、画面の端に通知を出す。戦闘は止めない
- **データ片そのものは実績ではない**。データ片は拾って集めるもの（「11. 世界観の見せ方」）で、「データ片を集めること」が実績の条件の一部になる
- 実績の例
  - ボルトボアを倒した（ボスごと）
  - 1つの武器で初めてクリアした（武器ごと）
  - データ片を初めて拾った／データ片をすべて集めた
  - 同じ系統のインプラントを3つそろえた
  - レジェンド装備を初めて手に入れた
- 実績は定義データとして書き、後から「データを1件足す」で増やせるようにする
- M5 で仕組みと最初の実績を入れる。仕上げ（M9）やテストプレイの中で実績を増やしていく前提
- 実績の報酬（ボス素材がもらえる、など）を付けるかどうかは未定
