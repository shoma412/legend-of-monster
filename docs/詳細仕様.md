# Legend of Monster 詳細仕様 v0.1（案）

企画書（[企画書.md](企画書.md)）で決めた骨組みを、実装できる粒度まで具体化したもの。数値はすべて初期値で、遊びながら調整する前提。

## 1. ラン（1回の挑戦）の構成：約30〜40分（2026-10-06 にエリアを長くした）

| エリア | 舞台 | 部屋の構成 | ボス |
|---|---|---|---|
| 1 | 下層スラム（電線とネオン看板の路地） | 最初の戦闘部屋 ＋ 途中5〜7部屋（道によって変わる）＋ 補給 ＋ ボス（合計8〜10部屋） | ボルトボア |
| 2 | 冷却プラント（凍った配管と蒸気） | 最初の戦闘部屋 ＋ 途中5〜7部屋（道によって変わる）＋ 補給 ＋ ボス（合計8〜10部屋） | クライオ・ワイバーン |
| 3 | 企業タワー最深部（サーバールーム） | 最初の戦闘部屋 ＋ 途中5〜7部屋（道によって変わる）＋ 補給 ＋ ボス（合計8〜10部屋） | オーバーロード |

- 1エリアの目安は約10〜13分（戦闘部屋1つ40〜60秒、ボス戦1.5〜2分）。エリアの長さ（通る部屋の数）は、出撃のたびに 8〜10 の範囲で変わる
- **分かれ道**：エリアに入った時点で、枝分かれした地図を作る（2026-10-04 変更）。部屋をクリアすると、地図の線でつながった部屋への扉が2〜3つ開き（補給とボスの前は1つ）、扉の上に「次の部屋の種類」がアイコンで出る。どちらに進むかをプレイヤーが選ぶ
- ボスを倒すと「次のエリアへ」の扉が開く。地図はエリアごとに新しく作る
- **エリアの地図**：左から右へ「最初の戦闘部屋 → 途中の5〜7列（1列に2〜3部屋）→ 補給（1部屋）→ ボス」。各部屋から次の列の2〜3部屋へ線が伸び、線でつながった部屋にだけ進める。どの道でも通る部屋は8〜10部屋。**ボスの1つ前は必ず補給**で、どの道を通ってもそこに集まる
- M キーで地図を出す（戦闘は止めない）。ポーズ画面の「地図」タブでも見られる。通った部屋、今いる部屋、進める道、もう行けない部屋が分かる。プレイ中の画面右上の小さい地図は出さない（2026-10-06 変更）
- ランの最初の部屋では、敵が出る前に「3・2・1」のカウントダウンを出す（カウントダウン中も動ける）
- エリアの最後は必ずボス部屋。ボスを倒すと全回復して次のエリアへ

### 部屋の種類
| 種類 | 内容 |
|---|---|
| 戦闘 | 雑魚の波（2〜3波）。クリアで経験値・クレジット・装備ドロップ |
| エリート | 強化個体1体＋取り巻き。報酬はレア以上の装備が確定 |
| 補給 | 戦闘なし。補給端末を調べると、HPを40%回復（1部屋につき1回）。**HP が満タンのときに調べると、回復の代わりに修復キットが1個もらえる**（2026-10-07 追加） |
| 闇市 | クレジットで装備・修復キット・消耗品・インプラントを買う。品ぞろえは毎回ちがう：並ぶ数は店ごとに5つか6つ。装備・修復キット・消耗品・インプラントは必ず1つずつ入り、残り（1つか2つ）は抽選で決まる（装備・消耗品・インプラントのどれか。修復キットは1つまで）。2026-10-07 に、決まった内訳（装備2・修復キット・消耗品・インプラント）から変えた |
| データ金庫 | 戦闘なし。装備3つから1つ選んで持っていく |
| 遭遇 | 戦闘なし。人物と会い、選択肢で結果が変わる（15「会話」） |

途中の部屋（5〜7列、1列に2〜3部屋）の中身は抽選で決まる。エリアごとに「エリート2〜3つ、特殊部屋3つ（補給・闇市・データ金庫・遭遇のうち別々の種類）、残りは戦闘」が入る。同じ列で隣り合う部屋は必ず違う種類にするので、扉の選択肢が全部同じ種類になることはない。どの列にも戦闘以外の部屋が1つは入り、足りなければ特殊部屋を足す（同じ種類の特殊部屋が1エリアに2つ出ることがある）。道によって通る部屋が変わるので、エリートと何度も戦う道も、エリートなしの道もありうる。

部屋が増えたぶん、1部屋進むごとの敵の増え方は緩やかにしてある（エリアの終わりの敵の量は、短かったころとほぼ同じ）。

- 最初の部屋は必ず戦闘部屋
- 戦闘のない部屋（補給・闇市・データ金庫・遭遇）は、入った時点で扉が開いている。データ金庫は何も取らずに進んでもよい
- 闇市・データ金庫で手に入れた装備はその場で身につけ、外した装備は足元に落ちる

## 2. 持ち帰り（ローグライト要素）

| 区分 | 中身 | 死んだとき |
|---|---|---|
| ラン中だけのもの | レベル、インプラント、装備、クレジット、修復キット | すべて失う |
| 持ち帰るもの | **ボス素材**（ボアコア／クライオコア／オーバーコア） | 倒したボスの分だけ残る |
| 持ち帰るもの | **データ片**（企業の実験記録の断片。「11. 世界観の見せ方」） | 拾った時点で残る |
| 持ち帰るもの | **実績**（「12. 実績」） | 解除した時点で残る |

- ボス素材はボスを倒した時点で確定する（その後で死んでも失わない）
- 1体につき1個。初回撃破だけ3個もらえる（序盤の強化を早めるため）

## 3. 隠れ家（拠点）での恒久強化

隠れ家は歩き回れる部屋で、置いてあるものに近づいて E で使う（2026-10-04 変更。落ちている装備を拾うのと同じ操作）。

| 置いてあるもの | 使うと |
|---|---|
| 武器ラック（武器ごとに1つ） | その武器を選ぶ。未解放なら、ボス素材を払って解放する。選んだ武器はその場で持ち替わり、試し斬りできる |
| 強化端末 | 恒久強化を買う画面を開く |
| 記録端末 | 記録・データ片・実績を見る画面を開く |
| 出撃ゲート | 近づくと依頼文が出る。E で、マップを選ぶ画面が開く（16「マップと周回」）。選んでいる武器で出撃する |

### ポーズ画面（2026-10-04 追加）
ラン中に Esc（または Tab）を押すと、ゲームが止まってポーズ画面が開く。隠れ家の端末で見られる情報を、そのままここでも見られる。

- タブ：ステータス（数値、装備3つの効果の詳細、インプラントの一覧と説明、発動中の種族ボーナス）／装備（バッグとの付け替え）／地図（今のエリアの全体）／恒久強化（買った段階を見るだけ。買うのは隠れ家）／記録／データ片／実績／操作（キーボードとマウスの図）／設定
- ボタン：「再開する」と「隠れ家に戻る」
- 「隠れ家に戻る」を押すと「今回の進捗はリセットされますが、よろしいですか？」と確認が出る。「はい」で隠れ家へ戻る（ラン中の装備・レベル・インプラント・クレジットは失う。すでに持ち帰りが確定したボス素材・データ片・実績は残る）
- レベルアップの3択が出ている間と、リザルトが出ている間は開かない

### 大剣の奥義（2026-10-04 決定）
大剣はほかの武器より少し弱いので、大剣にだけ奥義を用意する。片手剣と銃の奥義は、今は作らない。

- 使える条件：残りHPが最大の20%以下で、そのエリアでまだ使っていないとき（エリアごとに1回）
- 操作：右クリック
- 効果：自分を中心とした広い円（半径260px）の中の敵すべてに衝撃波。威力は、溜め斬り最大の1.75倍。シールド兵の盾でも防げない。範囲内の敵の弾も消える。使った直後は少しの間だけ無敵
- 使えるときは、キャラの周りに金色の輪が出て、画面に「右クリック：奥義」と案内が出る

### 武器の改造（2026-10-04 に案として追加。今は見送り。入れるかどうかは後で決める）
- 武器ごとに改造を3種類用意し、ボス素材で解放する
- 出撃前に、隠れ家の武器ラックで1つだけ選んで付ける（付けなくてもよい）。遊び方が変わる強化にする
- 改造の例
  - 大剣：溜めが速い（溜め時間 −40%）／溜め斬りが全方位になる／3段目が衝撃波を飛ばす
  - 片手剣：ジャストガードの受付が長い（0.15→0.3秒）／4段目が2回当たる／ダッシュ直後の一撃が必ず会心
  - 銃：弾が1体貫通する／拡散射撃が7発になる／連射が速いが1発が軽い
- 解放に必要な素材と、改造の中身の確定は、実装するときに決める

## 6. 装備（ハクスラ要素）

- スロットは3つ：**武器モッド**（選んだ武器を強化）、**防具**、**アクセ**
- ひと目で分かるように、スロットごとにアイコンを付ける（武器モッド＝刃、防具＝盾、アクセ＝指輪）。落ちている装備・闇市・データ金庫・画面右上の装備一覧で同じアイコンを使う。色はレア度
- レア度：コモン（白）／レア（水色）／エピック（紫）／レジェンド（金）。効果の数は1／2／3／4個
- レジェンドだけは、下の「固有効果」を1つ必ず持つ（効果4個のうち1つが固有効果、残り3つが通常の効果）

### 効果のプール
| 効果 | 範囲（レア度で上がる） |
|---|---|
| 攻撃力 +% | 5〜20% |
| 会心率 +% | 3〜12% |
| 会心ダメージ +% | 20〜60% |
| 攻撃速度 +% | 5〜15% |
| 最大HP + | 10〜40 |
| 移動速度 +% | 4〜12% |
| 被ダメージ −% | 3〜10% |
| 属性付与 | 電撃／熱／冷却／腐食のどれか（腐食は 2026-10-09 追加） |
| 撃破時HP回復 | 1〜4 |
| クレジット獲得 +% | 10〜30% |

### 属性と状態異常
- 属性は電撃／熱／冷却／腐食の4つ（腐食は 2026-10-09 追加。下の「27. 属性「腐食」」）。装備の「属性付与」やインプラントで攻撃に付く。複数の属性を同時に持てる
- **熱属性**の攻撃は必ず「燃焼」（3秒間の継続ダメージ）を付ける
- **冷却属性**の攻撃は必ず「減速」（40%減速）を付ける
- **電撃属性**は、それだけでは状態異常を付けない（インプラント「過電流」で敵を止められる）
- インプラントの「焼却弾」「冷却コア」は、それぞれ熱属性・冷却属性を攻撃に付けるもの。装備の属性付与でも同じ状態異常が付く
- **ボス**への減速は半分の効き目（20%減速）。凍結と停止はボスには効かない

### レジェンドの固有効果（例）
| 名前 | 効果 |
|---|---|
| ゼロデイ | 会心が出ると次の攻撃も必ず会心（この効果で出た会心は、さらに次の「必ず会心」を呼ばない） |
| ネオン・ハロー | ダッシュした場所に3秒間ダメージ床を残す |
| ブラックアイス | 冷却状態の敵を倒すと周囲を凍らせる |
| オーバーフロー | HP満タンのとき攻撃力 +40% |

拾うときは今の装備との比較を表示し、Eで付け替える（自動では付け替えない）。

### バッグ（2026-10-05 追加）
- ラン中に装備をしまっておける場所。6枠。死ぬと中身も失う
- 落ちている装備の上で F を押すと、身につけずにバッグに入る
- E で付け替えたとき、外した装備はバッグに入る（バッグがいっぱいなら、その場に落ちる）。闇市・データ金庫で手に入れたときも同じ
- ポーズ画面の「装備」タブで、いつでも「付ける（今の装備と入れ替え）」「外す（バッグへ。いっぱいなら外せない）」「捨てる（足元に落ちる）」ができる

## 7. インプラント（レベルアップ時の3択）

レベルは毎ラン1から。インプラントは「種族の部品」と「汎用の義体部品」に分かれる。同じ種族を集めるほど強くなるようにする（ビルドの方向性を作るため）。

### 種族（2026-10-06 に「系統」から変更）
- 種族は、ボス1体につき1つ。倒した機械から抜いた部品を、自分の体に組み込むという設定
- **1回の出撃で選択肢（レベルアップの3択、闇市、遭遇）に出るのは、「汎用」と「そのマップのボスの種族」と「持ち込みの種族（1つ）」だけ**。種族が全部でいくつに増えても、1回の出撃で出る種族は3〜4つに収まる
- そのマップの種族は、まだそのボスを倒していなくても出る
- 持ち込みの種族は、マップを選ぶ画面で選ぶ。選べるのは、倒したことのあるボスの種族のうち、そのマップに元からいない種族。持ち込みの枠は最初は1つで、恒久強化「部品棚の増設」で2つになる
- 同じ種族の部品を2種類持つと小さいボーナス、3種類で大きいボーナスが重なって発動する。数えるのは種類の数で、レベルではない
- マップを足すときは、その土地の種族も足す（データを1件足し、部品にその種族を書く）

### インプラントのレベル（2026-10-06 追加）
- インプラントにはレベルがある（Lv1〜5。上限はあとで増やしてもよい）。同じインプラントをもう一度手に入れると、Lv が1つ上がる
- レベルアップの3択には、持っているインプラントが「強化」として混ざって出る。新しいものを取るか、手持ちを伸ばすかを選ぶ。Lv が上限のものは出ない
- 闇市や遭遇部屋で手に入れたインプラントが手持ちと同じなら、それも強化になる
- 強化の幅は緩やか。Lv が1上がるごとに、効果の数値が「最初の値の2割」ずつ伸びる（Lv5 で最初の1.8倍）。例：オーバークロック +20% → +24% → +28% → +32% → +36%
- どの数値を伸ばすかは、インプラントごとに決める。伸ばさないもの：連鎖の数、止める秒数、貫通数、強欲プロトコルの被ダメージ、属性の付与そのもの
- 属性を付けるインプラントは、強化すると追加の効果が付く（帯電刃：会心率、焼却弾：継続ダメージの威力、冷却コア：減速中の敵が凍結する確率）
- 以前の「重ねがけ」（同じものを取ると効果が丸ごと2倍・3倍になる）は、このレベル制に置き換えた

### 新しいボスを作るときの決まり（2026-10-07 追加）
- **新しく作るボスの行動パターンは、既存のボスと似た行動を極力避ける。** 同じ部品（突進、落下、弾のばらまき など）の数値を変えただけの技を並べて済ませない
- 新しいボスには、**そのボスだけが使う固有の攻撃を、最低1つ**（主役になるボスや隠しボスは2つ以上）用意する。固有の攻撃は、前半（1段階目）から使わせる
- 既存の部品を使うのは、固有の攻撃を引き立てる脇役としてだけにする。同じマップの中で、同じ部品を主力にするボスを2体作らない
- 新しい攻撃の部品を足したら、「8. 敵」か、そのマップの章に、どのボスの固有の攻撃かを書く

### ボスの行動の選び方（2026-10-06 追加。マンネリ対策）
決まった順番で技を出すのをやめ、全ボス共通で次の仕組みにする。予告は今までどおり必ず出す（初見でも見て避けられる）。

- **状況で選ぶ**：その段階で使える技の中から、次の技を抽選する。技ごとに「近いとき向き／遠いとき向き」があり、プレイヤーとの距離が合う技が出やすい。直前に使った技は続けて出さず、2つ前に使った技は出にくい
- **反応**：プレイヤーが同じ動きを続けると、決まった技で返す。遠くに離れ続けると距離を詰める技（突進・跳びかかりなど）、甲羅持ちの背後に居続けると回転の一撃
- **連携**（後半）：2つの技を、間を空けずに続けて出す。締めのあとは、ふつうより長い隙（立ち止まる）ができる
- **重ねる**（後半）：本体の行動とは別に、残る攻撃（床、落下、線、振り子、召喚）が一定の間隔で差し込まれる
- **大技**：HP が残り 25% を切ると、1回だけ使う。名前が出て、ボスごとに違う。部品は3種類
  - **耐える**：ボスが力を溜める。溜めている間に一定のダメージ（最大HPの数%）を与えると中断でき、長いスタンになる。中断できないと、部屋の端まで届く輪が続けて広がる
  - **安全地帯**：部屋全体が危険になり、光る円（安全地帯）の中だけが助かる。場所を変えて数回くり返す
  - **追尾**：照準の円がプレイヤーを追いかけ、少しして止まり、その場所を攻撃する。続けて何個も来る

| ボス | 大技 | 部品 | 反応・連携・重ねる攻撃 |
|---|---|---|---|
| ボルトボア | 過充電 | 耐える（溜めている間、放電弾が出る） | 離れると突進。連携：跳びかかり→踏みつけ、2連突進→放電弾 |

| パイプサーペント | 配管破裂 | 追尾（攻撃した場所に汚水の床が残る） | 離れると潜行。連携：突進→噴射、毒液→突進。重ねる：汚水の床 |

## 12. 実績（2026-10-04 追加）

条件を達成すると解除される、普通のゲームの実績。

- 解除したときは、画面の端に通知を出す。戦闘は止めない
- **データ片そのものは実績ではない**。データ片は拾って集めるもの（「11. 世界観の見せ方」）で、「データ片を集めること」が実績の条件の一部になる
- 実績の例
  - ボルトボアを倒した（ボスごと）
  - 1つの武器で初めてクリアした（武器ごと）
  - データ片を初めて拾った／データ片をすべて集めた
  - 同じ種族のインプラントを3種類そろえた
  - レジェンド装備を初めて手に入れた

- 「武器で初めてクリアした」は、最後のボス（オーバーロード）を倒したときに解除する

- 実績の報酬（ボス素材がもらえる、など）を付けるかどうかは未定

## 14. 画面まわり（2026-10-05 追加）

### セーブ枠
- セーブ枠は3つ。タイトルのあとに選択画面を出し、枠ごとに進み具合（出撃回数、クリア回数、最高到達、実績、データ片、ボス素材）を見せる
- 空の枠は「はじめから」、データのある枠は「つづきから」と「消す」。消す前には確認を出す
- 保存は今までどおり自動（隠れ家の進行状況）。ラン途中は、ポーズ画面の「中断して終了」で中断できる（「20. テストプレイを受けた調整」）
- 隠れ家のメニューの「タイトルへ戻る」は、戻る前に確認を出す（どの枠に保存されているかを伝える）
- **書き出し／読み込み**（2026-10-06 追加）：セーブ枠の選択画面で、選んでいる枠のセーブデータを文字列（引き継ぎコード）にして書き出せる。別の場所（別のブラウザ・別のパソコン・公開先を変えたとき）で、その文字列を貼り付けて読み込むと、続きから遊べる
  - 書き出し：コードを表示し、「コピー」でクリップボードに入れる。空の枠は書き出せない
  - 読み込み：貼り付けたコードを、選んでいる枠に入れる。その枠にデータがあれば上書きになるので、その旨を出す。上書きされた枠の中断データは消える
  - 読めないコード、今より新しい版のデータは、読み込まずに理由を出す。古い版のデータは、今の形に直して読み込む
  - コードの中身は隠れ家の進行状況だけ（中断データと設定は含まない）。ブラウザから直接取り出したセーブデータの文字列（`{"version":…` で始まるもの）も、そのまま読み込める

### リザルト
- 持ち帰ったものを「ボス素材」「データ片」「実績」の3つの欄に分け、アイコンつきで並べる
- 「隠れ家に戻る」は画面上のボタンにする（Enter では戻らない）。攻撃の連打で誤って押さないよう、出てから少しの間は押せない

### 操作説明
- キーボードとマウスの図に、それぞれの操作を色分けして出す。武器ごとの左クリック・右クリックの違いも出す
- そのセーブデータで初めて隠れ家に入ったときに自動で出す。そのあとは、ポーズ画面と隠れ家のメニューの「操作」タブでいつでも見られる

### 設定
ポーズ画面と隠れ家のメニューの「設定」タブ。セーブ枠とは別に、ブラウザごとに1つ保存する。

| 項目 | 内容 |
|---|---|
| 音量 | 全体・BGM・効果音を、それぞれ10段階のゲージで変える。消音の切り替えもできる |
| 表示の大きさ | 画面に合わせる／960×540／1280×720／1600×900 |
| 画質 | 標準／高／最高（最高は標準の3倍の細かさ。上げるほどくっきりするが重くなる）。変えるにはゲームを読み込み直す（確認を出す） |
| フレームレート | 制限なし／30／60／120。すぐ反映される。最初は制限なし。どれを選んでもゲームの速さは変わらない |
| フルスクリーン | 切り替え |

### HP が少ないときの警告（2026-10-07 追加）
HP が少ないことに気づかずに倒れるのを防ぐため、見た目と音の両方で知らせる。段階は2つ。

| 段階 | 条件 | 見た目 | 音 |
|---|---|---|---|
| 警告 | HP が最大の 30% 以下 | 画面の縁が赤く、ゆっくり脈打つ。HP の棒が赤くなって点滅し、枠も赤くなる | 鼓動の音（約1秒に1回） |
| 危険 | HP が最大の 15% 以下 | 縁の赤が濃く、速く脈打つ。HP の棒の点滅も速くなる | 鼓動が速くなる（約0.6秒に1回） |

- 見た目は、部屋をクリアしたあとも HP が少ない間は出る。音は、戦っている間だけ鳴る（部屋をクリアしたあと、レベルアップの3択やポーズの間は鳴らない）
- 音は効果音の音量に従う。割合と間隔は `src/data/balance` の `FEEL.lowHp`

### 文字
- ゲーム中の文字はドット文字（DotGothic16）で統一する。古い端末の画面の雰囲気を出すため

### アイコン

- ボス素材は、恒久強化のタブと記録のタブ、リザルトに、アイコンつきで出す（種類が増えるので、隠れ家の画面上部やメニューの上の帯には出さない）。セーブ枠の選択では、種類の数と合計だけを出す

### 背景
- 部屋の床に、エリアごとの特色に合った背景を描く。ドット絵風の模様で、画像素材は使わずコードで描く
  - 下層スラム：ひび割れた路面、水たまりに映るネオン、垂れた電線、看板
  - 冷却プラント：金網の床、壁を走る配管、霜、通気口、冷却剤のたまり
  - 企業タワー：光る継ぎ目の床板、基板のような配線、壁ぎわのサーバーラック
  - 隠れ家：板張りの床、敷物、作業台、木箱、モニター
- 戦闘の邪魔にならないよう、暗めで薄く描く。置き場所は部屋ごとに変わる

### BGM
- エリアごとに道中の曲を変え、ボス戦もエリアごとに別の曲にする（タイトル、隠れ家、エンディングも別）
- 曲は無料の素材サイト「魔王魂」のループ用の曲を使う。タイトル画面に「音楽：魔王魂」と表記する。どの曲をどの場面で使っているかは `CREDITS.md` に記録する
- 曲を差し替えるときは、`src/data/audio.js` の対応表を書き換える
- 曲のファイルを読み込めなかったときは、コードで合成した曲（複数のセクションを順に並べて作ったもの）を代わりに鳴らす

## 15. 会話（2026-10-06 追加）

### 会話の画面
- 画面下に、顔イラスト、名前、本文を出す
- 顔イラストは 64×64 のドット絵で、コードで描く（外部素材は使わない）。表情ちがい（通常・怒りなど）を持てる
- 左クリック・E・Enter で次へ。文字が出ている途中なら、まず全部表示する。Esc でその会話をまるごと飛ばす（選択肢のある会話は、選択肢まで飛ぶ）
- 会話中はゲームを止める
- 自動で出る会話は、そのセーブデータでは一度だけ出す（既読をセーブデータに保存する）

### 会話が出る場面
| 場面 | 内容 |
|---|---|
| 隠れ家で話しかける | ハルと通信端末（ノイズ）に近づいて E。進行（倒したボス）に応じて話す内容が変わる。何度でも話せる |
| 出撃前と帰還後 | 初めての出撃前、各ボスを初めて倒して隠れ家に戻ったときに、短い会話を自動で出す |
| ボスの前 | そのボスの部屋に初めて入ったとき、戦闘前に数行。2回目以降は出さない |
| 道中の遭遇部屋 | 人物と会い、選択肢（2つ）で結果が変わる |

戦闘中に画面端へ流れる通信ログ（戦闘を止めない一言）は、これまでどおり残す。

### 部屋「遭遇」
特殊部屋の1つ。敵は出ない。人物に近づいて E で会話し、選択肢を選ぶ。1つの部屋で選べるのは1回。

| 遭遇 | 選択肢1 | 選択肢2 |
|---|---|---|
| 流れの商人 | HP を払って装備を1つもらう（HP が足りなければ断られる） | 断る（何も起きない） |
| 壊れかけの保守機 | 修復キットを1つ使って直す → インプラントを1つもらう | 部品を抜く → クレジットをもらう |
| 倒れた回収屋 | 装備を拾う → 次の戦闘部屋の敵が増える | そのままにする → HP が少し回復する |

数値（払う HP、もらえるクレジット、回復量、敵の増え方）は `src/data/balance` に置く。

### データの持ち方
- 人物、会話、遭遇はデータとして持ち、1件足せば増やせるようにする（`src/data/`）
- 顔イラストは `src/render/` に人物ごとに描く

## 16. マップと周回（2026-10-06 追加）

### マップ
- 1回の出撃で進むのは、1つのマップ。マップは、いくつかのエリアが順に並んだもの
- エリアの数は、マップ1〜5が3つ、マップ6は4つ（2026-10-09 決定。「30. マップ6」）
- 今の3エリア（下層スラム → 冷却プラント → 企業タワー）を「マップ1」とする。最終的にマップは7つにする（マップ2〜7は、作るまで「準備中」と表示する）
- 隠れ家の出撃ゲートを調べると、マップを選ぶ画面が開く。マップを選んで出撃する
- マップの最後のボスを倒すと、そのマップは「完了」。完了すると、次のマップが選べるようになる
- 完了したマップは、何度でも選び直せる

### エンディング
- エンディングは、7つのマップをすべて完了したときに出す（1回だけ）
- それまでは、マップを完了しても通常のリザルトだけを出す

### 周回
- すべてのマップを完了すると、次の周に進めるようになる。周が進むごとに敵が強くなる
- 物語上の理由：街が主人公を異物と認識して、修繕が激しくなる
- 画面には「2周目」のように周の数だけを出す（難易度を表す専用の言葉は出さない）
- 前の周も、いつでも選び直せる（素材集めや、武器を変えて遊ぶため）
- **次の周に進めるのは、マップ7までの7つすべてを完了したとき**（2026-10-07 変更）。前は「今あるマップをすべて完了したら」という開発中の扱いにしていたが、やめた。マップが7つそろうまでは、2周目には進めない。すでに2周目以降が開いているセーブデータは、そのまま（閉じ直さない）

| 周が1つ進むごとに | 変化 |
|---|---|
| 敵（雑魚・エリート・ボス）の HP | +15% |
| 受けるダメージ | +8% |
| 1部屋の敵の量 | 少し増える（1部屋ぶん奥のものとして数える） |
| もらえるボス素材 | 2周進むごとに +1 個 |
| 装備のレア度 | 1周ごとに 10% の確率で、1段上がる |

| 追加のルール | 内容 |
|---|---|
| 3周目から | エリートに特性が2つ付く |
| 5周目から | ボスが最初から後半の行動（HPが半分を切ったあとの行動）で始まる |
| 7周目から | 補給部屋の回復量が半分になる |

数値は `src/data/balance` に置く。

### 記録
- セーブデータに、マップごとの「クリアした回数」「クリアした最高の周」と、「選べる最高の周」を持たせる
- マップを選ぶ画面に、マップ名、エリアの並び、完了のしるし、クリア回数、選んでいる周、そのマップで出る種族、持ち込みの種族を出す（7「インプラント」の「種族」）
- リザルトに、マップ名と周の数を出す
- 実績を足す：「マップ1を完了」「3周目をクリア」「5周目をクリア」

## 19. 部屋の仕掛け（2026-10-06 追加）

戦闘部屋の一部に、その土地ならではの「仕掛け」が付く。仕掛けはデータとして持ち、エリアごとに「どの仕掛けが、どのくらいの確率で付くか」を決める。1つ足せば、ほかのマップのエリアにも付けられる。

- 仕掛けの付いた部屋は、部屋に入ったときの区画名に、仕掛けの名前が出る
- 仕掛けは、敵がいる間だけ動く（カウントダウン中と、クリア後は止まる）
- エリートの部屋、ボスの部屋、戦闘のない部屋には付かない

| 仕掛け | 内容 | 付くエリア |
|---|---|---|
| 落下する鉄骨 | 一定の間隔で、予告つきの鉄骨が落ちてくる。プレイヤーの近くと、部屋のどこかに落ちる。敵にも当たる（柵や橋げたも壊れる） | マップ3（戦闘部屋のうち、資材置き場は4割、高架の現場は3割、未完の塔は4.5割） |

数値（間隔、数、ダメージ）は、仕掛けの定義に書く。

### 武器ごとのステータス（2026-10-07 追加）
武器を選ぶと、技だけでなく本体の能力も少し変わる。出撃中ずっと効き、隠れ家の武器の説明と、ポーズ画面のステータスに出る。攻撃力は、武器ごとの技の威力ですでに差があるので、ここでは変えない。

| 武器 | 被ダメージ | 移動速度 | ねらい |
|---|---|---|---|
| 大剣 | −10% | −5% | 重装。殴り合いに強いが足が遅い |
| 片手剣 | ±0 | +5% | 標準。身軽 |
| 銃 | +10% | ±0 | 打たれ弱い。距離を取って戦う |
| ナックル | +5% | +10% | いちばん身軽。そのぶん、少し打たれ弱い |
| 大砲 | ±0 | −30% | いちばん足が遅い。位置取りが大事 |

**ガードの上からのダメージ**（2026-10-07 追加）：大剣と大砲は、盾や甲羅で防がれても **50% のダメージが通る**（吹き飛ばす力も半分）。対象は、シールド兵の盾とタンククラブの甲羅。片手剣・銃・ナックルは、今までどおり完全に防がれる。背後から当てたとき、盾が開いているとき、奥義のような「防げない攻撃」は、どの武器でも 100% 通る。

大砲だけ、**ダッシュ（回避）も遅い**（速さ 0.6倍）。進む距離と無敵の時間はほかの武器と同じで、かかる時間だけが延びる（0.16秒 → 約0.27秒）。無敵は0.25秒なので、ダッシュの終わりぎわは無敵が切れている。

### ダメージの数字：クリティカルの見せ方
「!」が数字の「1」に見えるため、付けない。クリティカルは、数字を大きく・黄色（アンバー）にして見分ける。

### 敵ぜんたいの強さ（2026-10-07 追加）
1周目の敵が強すぎたので、**敵ぜんたいの強さを、それまでの 0.65倍にした**。HP と、プレイヤーが受けるダメージの両方にかかる。雑魚にもボスにも、どのマップにも、同じようにかかる。周回の倍率（HP +15%・受けるダメージ +8% ずつ）は、この値に掛け算されるので、2周目以降も同じ割合で弱くなる。数値は `src/data/balance` の `ENEMY_SCALING.base`。この文書の、敵やボスの HP・ダメージの数字は、掛ける前の値。

### 修復キットを増やす手段（2026-10-07 追加）
- **敵が落とす**：雑魚は 4%、エリートは 35% の確率で、修復キットを1個落とす（装備・消耗品とは別に抽選）。近づいて E で拾う。ボスは落とさない（倒すと全回復するため）
- ほかの手段は、今までどおり：闇市で買う、補給端末を HP 満タンで調べる、恒久強化「修復キット増設」（出撃時の数 +1、2段）

### 最大HPが変わったときのHP（2026-10-07 追加。バグ修正）
装備の付け替え・インプラント・恒久強化などで最大HPが変わっても、**今のHPは回復しない**（前は、最大HPが増えたぶんだけHPも増えていたので、最大HPが増える装備の付け外しをくり返すと全回復できてしまった）。最大HPが減って今のHPより小さくなったときだけ、HPは最大HPまで下がる。隠れ家では、今までどおり常に満タン。

### 恒久強化「携行ポーチ」
消耗品の枠を増やす。1段ごとに +1 枠、2段まで（2枠 → 最大4枠。3・4 キーで使う）。必要素材はボアコア×2 → クライオコア×2。

### 近接攻撃の踏み込み
攻撃の出始めに、狙った方向の攻撃範囲の中にすでに敵がいるときは、踏み込まない（敵を押し込んだり、敵の攻撃に突っ込んだりしないように）。届く敵がいないときだけ、今までどおり踏み込む。

### 中断セーブ
- ポーズ画面（ラン中）に「中断して終了」を足す。押すと、その時点のランを保存してタイトルへ戻る
- 押せるのは、**部屋をクリアして、次の扉を選べる状態のとき**だけ（戦闘中は押せない）
- 保存するもの：マップと周、エリアと部屋の進み具合（地図）、HP、レベルと経験値、インプラント、装備、バッグ、消耗品、修復キット、クレジット、奥義の使用回数、そのランで手に入れたものの記録
- セーブ枠ごとに1つ。中断データがある枠は、セーブ枠の選択画面に「中断中」と場所が出る。その枠に入ると、隠れ家ではなく中断した部屋（クリア済みで、扉が開いた状態）から再開する
- 再開した時点で、中断データは消える（やり直しでの厳選はできない）。再開せずに枠を削除すれば、中断データも一緒に消える
- ゲームの更新でデータの形が変わったときは、中断データを捨てて隠れ家から始める

### フルスクリーン中の Esc
ブラウザの決まりで、フルスクリーン中の Esc はフルスクリーンの解除に使われる。

- Esc を使う場面（ポーズ画面を開く・閉じる、会話を飛ばす、マップ選択を閉じる、セーブ枠の選択から戻る、確認を取り消す）は、**すべて Tab でもできる**ようにし、画面の案内は「Tab」を先に書く
- Chrome / Edge では、フルスクリーンの間だけ Esc をゲームが受け取れるようにする（ブラウザの機能を使う。この間は、Esc の長押しでフルスクリーンが解ける）。対応していないブラウザでは、Tab を使う

### タイトル画面のメニュー
「PRESS ANY KEY」をやめ、**はじめる／設定／クレジット** のメニューにする（W・S か ↑・↓ で選び、Enter・Space・クリックで決定）。

## 21. 隠しボスと通行証（2026-10-07 追加）

「クリアするだけでなく、次のマップに進むための条件」として入れる。まずマップ3「建設区」に置き、マップ4に入る条件にする（マップ1→2、2→3 は今までどおり、クリアだけで進める）。

### ひび割れた壁
- 出撃ごとに、そのマップ全体（3エリア）の**どこか1部屋だけ**に、ひびの入った壁が出る。場所は毎回変わる。エリアの最初の部屋・ボス前の補給部屋・ボス部屋には出ない
- 地図には出ない。選んだ道によっては、その部屋を通らずに終わる（運として受け入れる。それが「隠し」）
- その部屋に入ると、通信でひとこと出る（「……壁の向こうに、反応がある」）。壁には、ひびと火花が見える（上か左の壁のどこか）
- **部屋をクリアするまで（敵が残っている間）は、壁を壊せない**。クリア後に攻撃すると崩れて、隠し扉が現れる。敵のいない部屋（補給・闇市など）では、すぐ壊せる
- 隠し扉に入るかどうかは選べる（案内に「倒すまで出られない」と出す）。入らずに先へ進んでもよい

### 隠しボス「アーキテクト」（異名：設計者）
建設区の機械に図面を配り続けている設計機。塔が完成しないのは、図面を書き換え続けているから。

- そのマップでいちばん強い。どのエリアで見つけても強さは同じ（HP 12000。クレーンタイタンの約1.25倍）。序盤に見つけた場合は、見送る判断もある
- 弱点は冷却。行動は3段階（HP 60% と 30% で変わる）
- 攻撃：固有の「方眼」「インク流し」（「22. 固有の攻撃と持続ダメージ」）に加えて、測量線（部屋を横切る線が順に光る）、押印（周囲への一撃）、突進、図面展開（橋げたの壁。2段階目から）、照準（追尾の円。2段階目から）。大技は「竣工」（安全地帯。4回くり返す）
- 倒すと **「建設区の通行証」** が手に入る（セーブに残る。1回取ればよい）。装備を3つ落とす（エピック以上を保証）。倒したあとは、扉から元の部屋に戻り、続きの扉を選ぶ
- 負けたときは、ふつうの死亡と同じ（その出撃は終わり）
- データ片は持たない。倒すたびに、素材「アーキテクトコア」を1個落とす（2026-10-08 変更。前は素材なし。恒久強化「記憶領域」に使う）。隠し部屋の中では中断できない
- 通行証を持っていても、ひび割れた壁は出る（装備が目当てで、また戦える）

### マップ4の条件
- マップ3 を完了していて、かつ「建設区の通行証」を持っていること
- マップを選ぶ画面で、足りない条件を出す（例：「建設区の隠しボスを倒すと、選べるようになる」）
- すでにマップ3 をクリア済みのセーブも、通行証はあらためて取る必要がある
- 実績「設計変更」（アーキテクトを倒した）を足す

今後のマップにも、同じ仕組み（マップの定義に「隠しボス」と「必要な通行証」を書く）で足せるようにする。

## 22. 固有の攻撃と持続ダメージ（2026-10-07 追加）

マップ3のボス3体と隠しボスは、ほかのボスと同じ部品の組み合わせが多く、似た動きに見えていた。そこで、**そのボスだけが使う攻撃**を足す。マップ1・2のボスは今のまま。どれも予告を出してから攻撃する。

| ボス | 固有の攻撃 | 中身 |
|---|---|---|
| スクラップハウンド | 刃の渦 | 鉄くずの刃を体のまわりで回しながら、追いかけてくる（前半3枚、後半4枚）。刃に当たると「裂傷」 |
| ガーダースパイダー | 張り糸 | 部屋を横切る糸を張る（前半3本、後半5本）。7〜8秒残り、触れている間は減速して、0.5秒ごとにダメージ。1本目はプレイヤーのいる場所を通る |
| クレーンタイタン | 溶接ビーム | ビームが、プレイヤーをゆっくり追って回る（回る速さに上限があるので、近くを回り込めば振り切れる）。当たると「炎上」。通ったあとに、燃える床が残る |
| アーキテクト | 方眼 | 部屋を6×4のマスに分け、市松模様の半分が光って攻撃する。続けて、残りの半分が光る（最終段階は3回） |
| アーキテクト | インク流し | プレイヤーの足元から、広がっていく床を置く（最終段階は、ボスの足元にも）。中にいると「腐食」 |

固有の攻撃は、前半（1段階目）から使う。これに合わせて、似た攻撃を減らす（クレーンタイタンの前半から鋲の弾を外す、アーキテクトの杭打ちと鋲の弾を主な技から外す、など）。

### 持続ダメージ（プレイヤーが受けるもの）
- 種類は3つ：**炎上**（0.5秒ごとに5、3秒）、**裂傷**（0.4秒ごとに4、3秒）、**腐食**（0.5秒ごとに6、3.5秒）。数値は `src/data/balance` の `STATUS.dots`
- 受けている間は、体のまわりにその色の輪が出て、付いたときに名前が出る
- **ダッシュすると消える**（振り払う）。付け直されると、時間は元に戻る。重ねがけはしない（あとから付いたものに入れ替わる）
- 被弾後の無敵の間も効く。被ダメージの補正は乗る
- **持続ダメージだけでは倒れない**（HP は 1 残る）。部屋をクリアすると消える

今後のマップの「環境」（毒など）も、この持続ダメージの仕組みを使って作る。

## 23. スキルツリー（2026-10-07 追加）

恒久強化（「3. 隠れ家（拠点）での恒久強化」）を、一覧から、線でつながった図に変える。何を取ると次に何が取れるかを、目で見て分かるようにするため。**強化の種類・段数・効果は変えない。**

### 形
- 強化の1段ぶんが、マス1つになる（強化骨格 5段 → マス5つ）。全部で34マス
- 中心から3本の枝が伸びる。**手前のマスを取ると、その先のマスが取れる**ようになる。中心につながったマスは、最初から取れる
- 強化の種類は3つに色分けする：**体**（強化骨格・装甲板・再生槽・基礎補強）、**技**（神経加速・補助演算・大剣の奥義・起動プログラム）、**備え**（修復キット増設・携行ポーチ・二重ダッシュ・関節強化・部品棚の増設・脚部強化）。種類は色と文字で見分け、どの枝にも混ざって並ぶ
- マスの状態は4つ：取得済み／取れる（手前を取ってあり、素材も足りる）／素材が足りない／まだ取れない（手前を取っていない）

### 値段（素材）
深いマスほど、複数のボスの素材が要る。

| 深さ | 必要な素材 |
|---|---|
| 1〜3段目 | 1種類を1個 |
| 4〜5段目 | 2種類 |
| 6段目以降 | 3種類 |

値段は強化ごとに決まっていて、配置では変わらない。逆に、**値段の「素材の種類の数」で、そのマスを置く深さが決まる**。

| 強化 | 前の値段（1段ごと） | 今の値段（1段ごと） | 置く深さ |
|---|---|---|---|
| 修復キット増設（2段） | クライオコア×2 | クライオコア×1 ＋ ボアコア×1 | 4〜5段目 |
| 携行ポーチ（2段） | ボアコア×2 → クライオコア×2 | ボアコア×1 → ボアコア×1 ＋ クライオコア×2 | 1枠目は1〜3段目、2枠目は4〜5段目 |
| 二重ダッシュ | クライオコア×3 | クライオコア×2 ＋ ボアコア×1 | 必ず4段目 |
| 部品棚の増設 | ハイドラコア×2 | ハイドラコア×1 ＋ クラブコア×1 ＋ サーペントコア×1 | 必ず6段目（いちばん奥） |
| そのほかの強化 | 1個 | 前と同じ（1種類を1個） | 1〜3段目 |

### ゲームバランスを変えないための決まり
スキルツリーにしても、前のゲームバランスとほぼ同じになるようにする。次のことを、どの配置でも守る（テストで確かめている）。

1. **全部そろえるのに必要な素材の数**：マップ1のぶんは 23個 → 23個、マップ3のぶんは 8個 → 8個で同じ。マップ2のぶんだけ 10個 → 11個（部品棚の増設が3種類になったぶん）。合計 41個 → 42個
   - 素材ごとの内訳：ボアコア 9→12、クライオコア 12→9、オーバーコア 2→2、サーペントコア 3→4、クラブコア 3→4、ハイドラコア 4→3、ハウンド・スパイダー・タイタンは同じ
2. **どのマスも、前より先のボスの素材は要求しない**（前にボアコアだけで買えたものは、今もボアコアだけで取れる、など）
3. **手前のマスは、そのマスより先のボスの素材を要求しない**。だから、あるボスまで倒した人は、そこまでの素材で取れるマスに、必ずたどり着ける（先のマップの素材に、道をふさがれない）。枝の根元は、最初のボス（ボアコア）のマス
4. 二重ダッシュは、そこまでの道も含めて素材6個で取れる（前は3個）。これが、前といちばん変わるところ

変わること：取る順番に制約ができる（前は、素材があれば何でも買えた）。3段目のマスは、その手前の2マスを先に取る必要がある。

### 配置のランダム性
- 配置は、**セーブデータごとに違う**。セーブデータを作ったとき（前の版のデータは、最初に読み込んだとき）に種（seed）を決めて保存し、以後は変わらない
- 変わるもの：どのマスがどの枝の何段目に来るか、枝分かれの形
- 変わらないもの：強化の種類と効果、マスの数、値段、上の決まり

### 素材の払い戻し（前の版のセーブデータ）
- スキルツリーになる前のセーブデータを読み込んだとき、買ってあった強化をすべて外し、**使った素材を、前の値段どおりに全部返す**
- 次に隠れ家へ入ったときに、1回だけお知らせを出して、スキルツリーの画面を開く
- 武器の解放（片手剣・銃）、実績、データ片、記録、通行証は、そのまま残す
- セーブデータの「強化の段数」は、取ったマスから数え直す（データを書き換えて段数だけ増やしても、効かない）

### 画面
- 隠れ家の強化端末と、メニューの「恒久強化」タブに、ツリーを出す。**円状に並べる**：円の真ん中が中心で、外の輪ほど奥の段。枝は、中心から放射状に広がる（2026-10-07：上から下へ並べる形から変えた）
- W・S でマスを選び、Enter で取る。マウスなら、クリックで選び、もう一度クリックで取る
- **拡大・縮小**：円の上でマウスのホイールを回すと、マウスのある場所を中心に拡大・縮小する（上に回すと拡大。1倍〜3倍）。拡大しているときは、引っぱって動かせる。十分に拡大すると、マスの下に強化の名前も出る。いちばん引くと、円の全体が真ん中に戻る。W・S で選んだマスが見えていなければ、見える位置まで動く
- 選んだマスの、名前・効果・必要な素材（持っている数／要る数）・状態を、円の右側に出す。その下に、色と文字の見方（凡例）を出す
- ポーズ画面（出撃中）では、見るだけ

### 案内（2026-10-09 追加）
マスが57個に増えて、「どれを取ればいいか」を読み解くのが大変になったので、画面のほうから教える。配置・値段・効果は変えない。

- **道筋**：まだ取れない奥のマスを選ぶと、中心（か、取ってあるマス）からそこまでの道が、水色に光る。右側に「ここまでの道　あと n マス」と、道ぜんぶで要る素材の合計（持っている数／要る数）、足りるかどうかを出す。1回も手に入れたことのない素材の名前は、ここでも伏せる
- **取ったらどうなるか**：右側に、恒久強化ぜんたいの合計を「今 → 取ったあと」で出す（例：「合計　最大HP +35 → +45」）。同じ数値を上げる強化（強化骨格・再生槽・基礎補強など）は、まとめて数える。数値で表せない強化（奥義、起動プログラム、武器ごとの強化）には出さない
- **取れるマスへ飛ぶ**：F キー（か、枠の右上の「今取れる n」をクリック）で、今すぐ取れるマスを順に選ぶ。今すぐ取れるマスがなければ、素材が足りないだけのマスを選ぶ。隠れ家の強化端末から開いたときは、最初から、取れるマスを選んだ状態で開く
- **端末の印**：今すぐ取れるマスがあると、隠れ家の強化端末の下の文字が「取れるマス n」（橙色）になる
- 計算は `src/logic/treeInfo.js`

## 24. マップ4「停電区」と、環境「暗闇」（2026-10-07 追加）

送電が止められた区画。街灯も看板も消えていて、機械たちは暗闇の中で動き続けている。雑魚の強さは、マップ1の3倍（マップ3は2.2倍）。3回に分けて作る（①暗闇の仕組みとエリア1 → ②エリア2 → ③エリア3と隠しボス）。

### エリアとボス
| エリア | 舞台 | ボス | 弱点 | ボス素材 | 種族 |
|---|---|---|---|---|---|
| 1 | 消灯街（灯りの落ちた通り） | ランプイーター（灯り喰い） | 熱 | モスコア | 蛾 |
| 2 | 地下変電所 | サーチライト・センチネル（照射番） | 電撃 | レンズコア | 番兵 |
| 3 | 主幹制御室 | ブレーカー（主幹遮断器） | 冷却 | ブレーカーコア | 遮断器 |
| 隠し | 補給部屋から開く道の奥（下の「隠しボスの出し方」） | ノクターン（影） | — | — | — |

隠しボスは置く。倒したときにもらえる通行証を、マップ5の条件にするかどうかは保留（決まるまで、マップ5の条件にはしない）。

### 環境（マップ全体に効く決まり）
「部屋の仕掛け」（一部の戦闘部屋にだけ付く）とは別に、**そのマップのすべての部屋に効く決まり**を「環境」と呼ぶ。マップの定義に書く。最初の環境が「暗闇」。

### 環境「暗闇」
- **見えるのは、自分のまわりだけ**。プレイヤーを中心にした円（半径 190px。画面の3分の1ほど）の中が明るく、外は暗い。暗さの強さと円の大きさは、遊んでみて決める（`src/data/environments.js`）
- **暗い場所の敵は、目の光だけが見える**（位置は分かるが、姿や動作は見えにくい）
- **攻撃の予告（赤い表示）・残る攻撃・敵の弾は、暗闇でも見える**。見えない攻撃で倒されることがないようにする
- **灯り**：
  - **非常灯**：戦闘のある部屋に2〜3本立っている。近づくと点いて、10秒のあいだ周り（半径 150px）が明るくなる。消えたら、また近づけば点く
  - **攻撃の光**：攻撃が当たった瞬間や爆発は、その場所を一瞬照らす
  - 倒すと光が残る敵もいる（下の「発光虫」）
- **目くらみ**（プレイヤーが受ける状態）：見える円が、しばらく狭くなる（0.55倍、4秒）。ダッシュでは消えない
- 明るいマップ（マップ1〜3）では、何も変わらない。「照らされている」という条件は、明るいマップでは常に満たされる

### 雑魚敵（マップ4から出る）
| 敵 | 動き |
|---|---|
| 忍び寄り | 暗闇の中を速く近づいてきて、触れるとダメージ。**非常灯や攻撃の光に照らされている間は、動けない**（プレイヤーのまわりの円は、光に数えない）。灯りの近くで戦うと楽になる |
| 灯り割り | 点いている非常灯へ向かっていき、壊す（壊された非常灯は、しばらく点かない）。点いている非常灯がなければ、プレイヤーを殴りに来る |
| 発光虫 | 弱くて、まっすぐ寄ってくる。**倒すと、その場に8秒ほど光が残る** |

エリア1では、これに既存の敵（ドローン・自爆ボット・スナイパー）を混ぜる。

### ボス「ランプイーター」（エリア1。異名：灯り喰い）
灯りに集まり、灯りを食べる蛾の機械。新しいボスを作るときの決まりどおり、そのボスだけの攻撃を持つ。

| 攻撃 | 中身 |
|---|---|
| **消灯**（固有） | 点いている非常灯をすべて消し、そのうち1本を食べて壊す（しばらく点かない）。そのあと暗闇にまぎれて位置を変え、予告つきの突進を1〜2回 |
| **鱗粉**（固有） | プレイヤーのまわりに、鱗粉の雲を3つまく。しばらく残り、中にいると「目くらみ」になる |
| 急降下 | 予告線つきの突進（壁に当たると隙） |
| 羽ばたき | 足元からの衝撃波の輪 |
| 大技「全消灯」 | 非常灯をすべて壊し、プレイヤーを目くらみにしたうえで、暗闇からの突進を4回 |

HP が半分を切ると、消灯のあとの突進が2回になり、鱗粉の雲が増える。非常灯が残っているほど、姿が見えて戦いやすい。

### 種族「蛾」（ランプイーター由来。光と目）
| 部品 | 効果（Lv1） |

## 25. マップをクリアしたあとの持ち越し（2026-10-08 追加）

マップをクリアしても、次の出撃に何も残らないのは不親切なので、少しだけ残るようにする。先のマップほど敵が強いのに、毎回レベル1・装備なしで始まるため。

### いつ・何が残るか
- **マップをクリアしたとき**（そのマップの最後のボスを倒したとき）にだけ、次の出撃への持ち越しができる。死んだときは、何も残らない
- 残るのは2つ
  - **クレジット**：クリアした時点で持っていた額の半分（端数は切り捨て）
  - **インプラント**：クリアした時点で持っていたものの中から、次の出撃のときに選んだもの。**レベルは1に戻る**
- レベル・装備・消耗品・修復キットは、持ち越さない

### 使い方
- 持ち越しは、**次の1回の出撃**で使われる（どのマップに出撃してもよい）。出撃した時点で消える。その出撃で死んでも、戻らない
- 出撃先を選ぶ画面に「持ち越し」の欄が出る。クレジットの額と、インプラントを選ぶ枠（◀ 名前 ▶。「なし」も選べる）が並ぶ
- 選んだインプラントは、出撃した最初から Lv1 で持っている。種族ボーナスの数にも入る
- 続けてクリアすれば、また持ち越せる（そのとき持っているものから選び直す）
- リザルト画面に、持ち越せるもの（クレジットの額と、インプラントを選べること）を出す

### 持ち越せるインプラントの数
- 最初は **1つ**。恒久強化「記憶領域」（1段）を取ると **2つ**になる
- 「記憶領域」の値段：アーキテクトコア×1 ＋ ノクターンコア×1（**隠しボス2体の素材**。スキルツリーの4〜5段目に、今の配置を変えずに1マス足す）
- このために、隠しボスは倒すたびに素材を1個落とすようにする（アーキテクト → アーキテクトコア、ノクターン → ノクターンコア）。**すでにアーキテクトを倒しているセーブデータには、アーキテクトコアを1個渡す**（もう一度倒さなくてよい）

### 細かい決まり
- 持ち越したインプラントが、出撃先のマップの種族でも持ち込みの種族でもない場合：持ってはいるが、その出撃中にレベルを上げる選択肢には出ない（今の「選択肢に出る種族」の決まりのまま）
- 「起動プログラム」（最初に1つ選べる）とは別に効く。周回（2周目以降）でも同じ
- 中断して再開した出撃には関係しない（持ち越しは、新しく出撃するときにだけ使われる）

## 26. 操作方法（マニュアル／オート）（2026-10-08 追加）

プレイヤーの向きの決め方を、設定で選べるようにする。

### 設定
- 設定画面に「操作方法」を足す。**マニュアル**（今までどおり。最初はこちら）と**オート**を選べる
- タイトルの設定と、出撃中・隠れ家のメニューの設定の、どちらからでも変えられる。変えたらすぐ効く
- 音量などと同じく、セーブ枠とは別に保存する（どの枠でも同じ設定）

### マニュアル
今までどおり。マウスカーソルのあるほうを向き、攻撃もその向きに出る。

### オート（2026-10-08：ロックオンの形に変更。最初は「その瞬間に、いちばん近い敵を向く」だった）
- **敵を1体ロックオンして、その敵のほうを向き続ける**。攻撃・溜め・射撃・構えは、その向きに出る。ロックオンした敵には、印（まわりの輪）が出る
- **R キー：ロックオンを、次に近い敵へ切り替える**（押すたびに、近い順に回る。オートのときだけ効く）
- 敵がいないときは、動いている向きを向く（止まっていれば、最後の向きのまま）
- マウスは、クリック（攻撃・特殊）にだけ使う。カーソルの場所は関係なくなる
- 振っている間は向きが変わらない（マニュアルと同じ）。ダッシュの向きは、今までどおり移動キーで決まる

| 場面 | どうなるか |
|---|---|
| 最初（ロックオンしている敵がいない） | いちばん近い敵をロックオンする。ボスがいれば、ボス |
| R を押す | 次に近い敵へ切り替える。いちばん遠い敵の次は、いちばん近い敵に戻る |
| ロックオンした敵を倒した・ロックオンできなくなった | そのとき、いちばん近い敵（ボスがいれば、ボス）に移る |
| 新しい敵が、自分のすぐ近くに出た | ロックオンはそのまま（R で切り替える） |
| **暗闇** | **見えている敵（自分のまわりの円の中か、灯りに照らされている敵）だけ、ロックオンできる**。ロックオンした敵が暗い所へ出たら、外れる |
| 明滅機が消えている間・出現の予告中の敵・潜っているボス | ロックオンできない（していたら、外れる） |
| 敵はいないが、壊せるものがある（柵、橋げた、ひび割れた壁） | いちばん近い「壊せるもの」をロックオンする。敵がいる間は、敵が先（R でも、壊せるものには切り替わらない） |
| 閃光（閃光持ち、センチネル）の予告が出ている間 | オートだと目を背けられないので、その間だけ、動いている向きを向く（ロックオンは外れない）。離れる方向に動けば、背けたことになる |
| ブレーカーの「残像」が並び直した瞬間 | ロックオンを、いちばん近いもの（本物か偽物か、どれでも）に付け直す。本物を向いたままだと、向きで本物がばれるため |

### オートの位置づけ
- オートは、操作が簡単な代わりに、狙う相手を選べない（奥の敵を先に倒す、ボス戦で雑魚を片づける、柵を壊す、などはマニュアルのほうが有利）。これは一長一短として、そのままにする
- **これから作る敵・ボス・仕掛けは、今までどおりマニュアルを前提に作る**。オートのための例外（上の表の、閃光と残像のようなもの）は、これ以上は増やさない

## 27. 属性「腐食」（2026-10-09 追加）

4つ目の属性。今までの「属性は、今は増やさない」という決まりを、ここで変える。今の3つ（熱＝削る、冷却＝足を止める、電撃＝広げる）とかぶらないように、**敵を弱らせる**役割にする。

### 効果
- 色は黄緑。攻撃が当たると、敵に **「腐食」（4秒）** が付く。当て直すと、時間が戻る（重なって強くはならない）
- **腐食中の敵は、受けるダメージが +15%**（ボスは +8%）。自分の攻撃だけでなく、設置物・連鎖放電・燃焼など、すべてのダメージに効く
- 腐食中の敵には、黄緑の泡の印が出る
- 腐食を付けた、その1発のダメージは増えない（付いたあとのダメージから増える）

### どこで手に入るか
- **装備の「属性付与」**：電撃・熱・冷却・腐食の4つから、どれか1つが付く
- **汎用インプラント「腐食液」**：攻撃に腐食属性を付ける。Lv2 以降は、腐食中の敵を倒すと、近くの敵に腐食が移る。汎用なので、どのマップでも選択肢に出る（インプラントは全部で69種、汎用は9種になる）

### 弱点
- **今いるボスの弱点は変えない**。腐食が弱点のボスは、マップ5以降で出す
- そのぶん、今は「弱点を突いて1.5倍」ができない属性になる。代わりに、どの敵にも +15% が効く

### 名前について
ボスの攻撃でプレイヤーが受ける持続ダメージにも、同じ「腐食」という名前のものがある（インク流し）。中身は別物（あちらは継続ダメージ、こちらは敵が受けるダメージが増える）。

## 28. マップ5「溶解区」と、環境「酸の雨」（2026-10-09 追加）

### 環境「酸の雨」（マップのすべての部屋に効く決まり）
- 戦闘の間、**13秒ごとに、2秒の予告（画面が黄緑になり、「Acid Rain」と出る）のあと、5秒だけ雨が強まる**。これをくり返す。敵がいない間（カウントダウン中、部屋をクリアしたあと、補給や闇市の部屋）は降らない
- 雨の間、**屋根の外にいると、0.6秒ごとに小さなダメージ**を受ける（これで倒れることはない。ダッシュでは防げない）
- **屋根**：戦闘のある部屋に、2〜3か所ある（瓦ぶきの屋根。四角い範囲）。下にいれば、雨に当たらない。屋根は、下にいるものが見えるように、少し透けて描く（自分が下にいる屋根は、もっと透ける）
- **雨は敵にも降る**。屋根の外にいる敵には「腐食」が付く（受けるダメージ +15%。ボスは +8%）。雨のときに攻めるか、屋根で待つかを選ぶ
- 画面の右下に、雨までの秒数（降っている間は、残りの秒数）を出す

### 隠しボス「カタリスト」（異名：触媒）

## 29. 新武器：槍とチャクラム（2026-10-09 追加）

今の5つ（大剣＝重い一撃、片手剣＝手数と防御、銃＝遠距離の連射、ナックル＝超近距離の連打、大砲＝遅くて重い爆発）にない役割を足す。全部で7種類になる。

### 槍（解放：タイタンコア×2）
「貫く」武器。前へ長く、横に狭い。並んだ敵に強く、囲まれると弱い。

| | 中身 |
|---|---|
| 通常攻撃 | 3段の突き（1・2段目は威力20・届く距離130px、3段目は威力30・150px）。扇の広さは16度（とても狭い）。**届く範囲にいる敵を、すべて貫く** |
| 特殊アクション（右クリック） | **突進突き**：向いている方向へ190px踏み込み、通り道の敵すべてに70ダメージ（重い攻撃）。踏み込んでいる間は無敵。クールダウン5秒 |
| ステータス補正 | 会心率 +5%、被ダメージ +5% |

投げて、戻ってくる輪。投げる位置と、自分の立ち位置で、当たり方が変わる。

|---|---|
| 通常攻撃 | 輪を投げる（威力22）。300px 飛ぶか壁に当たると、**手元へ戻ってくる**。行きと帰りで、同じ敵に2回当たる。敵をすべて貫く。**戻るまで、次は投げられない**（押している間、戻りしだい投げ続ける） |

| ステータス補正 | 移動速度 +5%、被ダメージ +5% |

- インプラント「拡張ブレード」の「弾が1体貫通」は、もとから貫くので、チャクラムには効かない
- 隠れ家の武器ラックは、7つ並ぶように、間を詰めて広げる

### 武器の強さの調整（2026-10-09 追加）
7種類を遊び比べた感覚（上から、銃・ナックル ＞ 大砲・片手剣 ＞ 槍・大剣 ＞ チャクラム）と、調整した。最初は手計算の目安（ナックルがいちばん高く、チャクラムがいちばん低い）をもとにしたが、ゲームの中で実際に測ると（止まっている敵1体を30秒殴り続ける）、ナックルは通常37・特殊込み56で、飛び抜けてはいなかった。手計算は、当てたときの一瞬の止まり（ヒットストップ）を入れていなかった。

| 武器 | 変えたこと | ねらい |
|---|---|---|
| ナックル | **変えない**（いったんゲージの溜まりを 4 → 3 に下げたが、元に戻した） | 実際に測ると、ナックルの数字は飛び抜けていなかった（強く感じるのは、数字ではなく使いやすさ） |
| チャクラム | 威力 22 → 28、戻りの速さ 680 → 820 | 往復のダメージを 44 → 56 に。往復も少し短く |
| 大剣 | 振っている間の移動速度 0.45 → 0.55 | 数字ではなく、当てやすさを上げる |

槍・大砲・片手剣・銃は変えない（銃は、数字ではなく「遠くから安全に撃てる」ことで強い。下げると、ただ時間がかかる武器になる）。

## 30. マップ6「送風区」と、環境「強風」（2026-10-09 追加）

街ぜんたいの空気を入れ替える、巨大な換気設備の区画。**エリアは4つ**（マップ1〜5は3つ）。雑魚の強さは、マップ1の5倍（マップ5は4倍）。5回に分けて作る（①強風とエリア1 → ②エリア2 → ③エリア3 → ④エリア4 → ⑤隠しボス）。この章には、全体の決まりと①までを書く。②〜⑤は、作る回ごとに書き足す。

### 入る条件
- マップ5 を完了していて、かつ「溶解区の通行証」（マップ5の隠しボス「カタリスト」を倒すと手に入る）を持っていること（保留にしていた通行証の使い道を、ここで決めた）

### エリアとボス
| エリア | 舞台 | ボス | そのボスだけの仕掛け | 弱点 | ボス素材 | 種族 |
|---|---|---|---|---|---|---|
| 1 | 吸気口 | インテーク（吸い込み口） | 正面のものを吸い寄せる。部屋のがれきを吸い込んで、まとめて吐き出す | 腐食 | インテークコア | 吸気 |
| 2 | 送風路 | ダクトクローラー（管這い） | 壁の通気口に潜り、別の口から飛び出す。出てくる口は直前に光る | 熱 | （②で決める） | 管 |
| 3 | 風見の庭 | ウェザーベーン（風見） | 正面に盾を持ち、風上を向く。風向きが変わると向きも変わるので、回り込んで背中を攻める | 電撃 | （③で決める） | 風見 |
| 4 | 排気塔 | サイクロン（大渦） | 部屋に竜巻を出す。大技は「台風の目」で、真ん中の狭い円だけが安全になる | 冷却 | （④で決める） | 渦 |
| 隠し | 補給部屋から開く道の奥 | カーム（凪） | 風を止める。中身と出し方は、⑤で決める | なし | （⑤で決める） | — |

- ②〜④のボスの中身は、作る回に、今あるボスと似ていないかを確かめ直す（①のインテークは、マップ3のクレーンタイタンの「磁力」と似ないように、作る前に直した。下の「ボス『インテーク』」）。エリア3のウェザーベーンの盾は、マップ2のタンククラブの甲羅と似るおそれがあるので、③の案で直す
- 5つ目の属性は、足さない
- 素材「カタリストコア」の残りの使い道：マップ6の恒久強化（④で足す）の値段に使う

### エリアが4つになることで変わること
- 装備のレア度の表（「20. テストプレイを受けた調整」の「装備のレア度」）に、4段目を足す：コモン 42・レア 38・エピック 12・レジェンド 8（3段目は 50・36・9・5）。4つ目のエリアまで行くごほうび
- 雑魚の強さは、エリアが1つ進むごとに 1.6倍の決まりが、4つ目にもそのままかかる（エリア4の雑魚は、エリア1の約4.1倍）。きつすぎたら、遊んでから下げる

### 環境「強風」（マップのすべての部屋に効く決まり）
- 戦闘の間、**12秒ごとに、2秒の予告（画面のふちが水色に明滅し、風向きの矢印と「Gale」が出る）のあと、4秒だけ強い風が吹く**。これをくり返す。風向きは、予告のたびに、上下左右から選ばれる。敵がいない間（カウントダウン中、部屋をクリアしたあと、補給や闇市の部屋）は吹かない
- 風の間、**プレイヤーも、敵も、弾（敵の弾も、こちらの弾も）も、風下へ流される**。ダッシュ中も流されるので、追い風のダッシュは伸び、向かい風のダッシュは縮む
- **風そのものにダメージはない**。流された先に敵の攻撃や穴があると危ない、という形にする
- **遮風板**：戦闘のある部屋に、2〜3か所ある（十字に組んだ板。どの向きの風でも、陰ができる）。板の風下側の陰にいれば、流されない。予告の間と風の間は、陰になる場所を、薄い水色で示す。板は通り抜けられる（壁ではない）
- ボス、置かれたもの（がれきなど）、杭を打った「錨打ち」は、流されない
- 画面の右下に、風までの秒数（吹いている間は、残りの秒数）と、風向きの矢印を出す
- 数値は `src/data/environments.js`、動きは `src/game/wind.js`

### 雑魚敵（マップ6から出る）
| 敵 | 動き |
|---|---|
| 風乗り | まっすぐ寄ってくる、軽くて速い敵。**追い風（風が、プレイヤーのほうへ吹いている）の間は、動きが 2.2倍に速くなり、一気に飛び込んでくる**。向かい風では、ほとんど進めない |
| 錨打ち | 距離を取って撃つ。**風の予告が出ると、床に杭を打つ。風の間は流されず、その場から、ふだんの 1.8倍の速さで撃つ**。杭を打っている間は動けない（足元に、橙色の杭の印が出る） |

エリア1では、これに既存の敵（グラント・自爆ボット・シールド兵・スナイパー）を混ぜる。

### ボス「インテーク」（エリア1。異名：吸い込み口、弱点：腐食、素材：インテークコア）
区画の空気を吸い込んで、奥へ送る機械。フィルターを自分で外してしまい、吸ったものをそのまま吐く。

| 攻撃 | 中身 |
|---|---|
| **吸引**（固有） | 口を向けた**正面の扇形**にあるものを、吸い寄せる。吸っている間、ゆっくりこちらへ向き直るので、**横や後ろへ回り込めば、吸われない**。ダッシュ中と、遮風板をはさんで口の反対側にいる間も、吸われない。口のすぐ前まで寄せられると、噛み砕かれる（くり返しダメージ）。**扇形の中にある「がれき」も吸い込んで、飲み込む** |
| **吐き出し**（固有） | 吸引のあとに、必ず出す。飲み込んだがれきを、扇形に吐く。**弾の数は、飲み込んだがれきの数で決まる**（4発 ＋ がれき1個につき2発。18発まで）。飲み込んだ数は、ボスの背中の橙色の印で分かる。壁に当たった弾は、半分の確率で、がれきになって床に残る（次の吸引で、また吸われる） |
| 羽根の破片・地ならし・踏みつけ | 既存の部品（脇役。うずまきの弾、衝撃波の輪、周囲への一撃） |
| 大技「全開」 | 部屋ぜんたいを、7秒吸う（どこにいても吸われる）。**遮風板の、口の反対側の陰にいれば、吸われない**。ただし、こちらにいちばん近い板から順に、赤く揺れてから飛ばされていく（1枚は残る。飛んだ板は、あとで戻る）。部屋のがれきは、すべて飲み込み、最後に、全方向へ吐く |

- **がれき**：最初の吸引のときに、部屋に5個まかれる。**攻撃で壊せる**。吸われる前に壊しておけば、吐き出しの弾は、いちばん少ない4発で済む。部屋のがれきは、8個まで
- ボスが吸っている間は、環境の風は止まる（風と吸い込みが、同時に来ないようにする）
- HP が半分を切ると、吸う扇形が広がり（80度 → 100度）、向き直るのが速くなる
- クレーンタイタンの「磁力」（どの向きにいても引かれて、最後に周りを叩く）との違い：吸うのは正面だけで、回り込んで避ける。吸ったがれきが次の攻撃になり、がれきを壊して弱められる

### 種族「吸気」（インテーク由来。風と引き寄せ）
| 部品 | 効果（Lv1） |
|---|---|
| 追い風 | 風の間、移動速度 +20% |
| 吸い寄せ | 攻撃が当たった敵を、手前に引き寄せる（ボスと、置かれたものは動かない） |
| 集塵 | 敵を倒すと、近くの敵を、倒した場所へ引き寄せる |
| 風よけ | 風と吸い込みで流される量 −50% |
| 吹き返し | 風の間、与えるダメージ +12% |

種族ボーナス：2種類で「風の間、ダッシュの回復が 20% 速くなる」、3種類で「引き寄せた敵・風に流されている敵へのダメージ +15%」。

- 「集塵」は、最初の案では「落ちているクレジットを吸い寄せる」だったが、このゲームのクレジットは倒した時点で手に入り、床に落ちないので、上の効果に変えた

### 一緒に足すもの（①）
- ボス素材「インテークコア」。データ片4つ（データ金庫3、ボス1）。実績「吸い込み口狩り」
- ボス前の会話と、帰ってきたときの会話。ハルと通信端末の話題を1つずつ
- 背景（吸気口：格子の床、床に埋まった換気扇、壁ぎわのダクト、紙くず）
- BGM：**まだ選んでいない**。新しい曲を入れるまで、マップ1の曲（道中 サイバー38、ボス ネオロック80）を借りている。曲のダウンロードは、曲名を示して、許可をもらってからする
- 恒久強化は、①では足さない（④で足す）

## 31. モバイル版（2026-10-09 追加）

スマホ・タブレットで公開ページを開いたときだけ、指で遊べる形になる。**パソコンで開いたときは、何も変わらない**（画面も、操作も、設定も）。2段階で作る。この章には、第1段階を書く。

### いつモバイル版になるか
- **指で触る画面で、主な入力が指の端末**（スマホ・タブレット）で開いたとき。タッチ画面つきのノートパソコンは、主な入力がマウスなので、パソコン版のまま
- 見分けは、ページを開いたときに1回だけ行う。セーブデータや設定には、何も書かない（同じセーブを、パソコンとスマホの両方で使っても、困らない）
- 確認用：アドレスの末尾に `?mobile=1` を付けると、パソコンでもモバイル版になる。`?mobile=0` で、スマホでもパソコン版になる
- 見分けの決まりは `src/logic/device.js`

### 第1段階：画面のスティックとボタン
ゲームの画面の上に、半透明のスティックとボタンを重ねる。横長のスマホでは、多くがゲームの画面の左右の余白に収まる。

| 部品 | 場所 | 働き |
|---|---|---|
| スティック | 左下 | 倒した向きに動く。メニューでは、大きく倒すと、上下左右のキーを1回押したことになる（タブの切り替え、項目の選択） |
| 攻撃 | 右下（大きい） | 押している間、攻撃する（長押しで、大剣の溜め斬り・銃の連射） |
| 特殊 | 攻撃の上 | 特殊アクション（右クリックと同じ） |
| ダッシュ | 攻撃の左 | ダッシュ回避（Shift と同じ） |
| 調べる | ダッシュの上 | 扉を選ぶ・買う・装備を身につける・話しかける（E と同じ）。メニューでは「決定」にもなる |
| キット／しまう | 特殊の上 | 修復キットを使う（Q）／装備をバッグに入れる（F） |
| メニュー／決定 | 右端の上 | ポーズ画面を開く・閉じる・会話を飛ばす（Tab）／決定（Enter） |
| 標的／地図／全画面 | 左端の上 | ロックオンの切り替え（R）／エリアの地図（M）／フルスクリーン（できる端末だけ出る。iPhone には出ない） |
| 1〜4 | 下（スティックの右） | 消耗品を使う。レベルアップの3択も選べる（3択は、カードを直接触っても選べる） |

- ボタンに小さく書いてある文字（E、Q、F、Shift）は、画面の案内（「E：扉を選ぶ」など）に出てくるキーの名前
- **向きは、いつもオート**（ロックオン。「26. 操作方法」）。設定の「操作方法」がマニュアルでも、モバイル版ではオートになる（設定は書き換えない）
- 画面を直接触っても、攻撃はしない（攻撃は、攻撃ボタンで）。タイトル・セーブ枠・マップ選択・会話・メニューのボタンやタブは、今までどおり、直接触って押せる
- 消耗品のうち、狙う場所が要るもの（投げるもの）は、向いている先に使う
- スマホを縦に持っているときは、「横向きにしてください」と出す
- 戦闘画面の右下の文字（WAVE、風や雨までの秒数、灯りの数）は、ボタンに隠れないよう、左へずらす
- 部品は `src/mobile/touchControls.js`、入力の受け渡しは `src/game/touchInput.js`

### 第2段階：言葉・文字・メニュー（2026-10-09 追加）
どれも、モバイル版のときだけ。パソコンでは、今までどおり。

- **言葉**：画面の案内は、キーボードとマウスの言葉で書いてある。モバイル版では、画面に出す直前に、ボタンの名前に言い換える（元の文は書き換えない）。例：「E：扉を選ぶ」→「調べる：扉を選ぶ」、「閉じる（Tab）」→「閉じる（メニュー）」、「Enter」→「決定」、「クリック」→「タップ」、「右クリック」→「特殊ボタン」、「W・S」→「スティック上下」。言い換えの決まりは `src/logic/mobileWords.js`
- **文字の大きさ**：14px までの小さな文字を、2px 大きくする（11 → 13、12 → 14、14 → 16）。それより大きな文字は、そのまま。戦闘画面の上の帯（HP・ダッシュ・特殊アクションの名前など）は、ゲージの間が詰まっているので、大きくしない
- **画質**：モバイル版の初期値を「高」にする（スマホの画面は点が細かく、「標準」だと文字がぼやけるため）。重いときは、設定で「標準」に下げられる。自分で選んだ値は、そのまま
- **メニューの「拡大」ボタン**：メニューの右上に出る。押すと、メニューぜんたいが 1.45倍になり、指でなぞって動かせる。「戻す」で元に戻る。確認の案内（はい／いいえ）が出るときは、自動で戻る
- **スキルツリー**：枠の右下に「−」「＋」のボタンを出す（ホイールの代わり）。拡大中は、指でなぞって動かせる
- **戦闘用のボタンを隠す**：タイトル、セーブ枠、マップ選択、メニュー（ポーズ画面）、レベルアップの3択、リザルトの間は、攻撃・特殊・ダッシュ・調べる・キット・しまう・標的・地図・1〜4 を隠す（スティック・メニュー・決定・全画面は残る）
- **操作方法はオートに固定**（2026-10-09 決定）：設定の「操作方法」には「オート（固定）」とだけ出て、選べない。設定の中身は書き換えないので、同じブラウザをパソコンとして使ったときの操作方法は、そのまま残る
- **「操作」タブ**：キーボードの図の代わりに、画面のボタンとその働きの一覧、武器ごとの攻撃と特殊を出す

### まだやっていないこと（第3段階で決める）
- **メニュー・装備の比較の並べ直し**：文字は少し大きくなっただけで、スマホではまだ小さい。「拡大」ボタンは、並べ直すまでのつなぎ。どの画面から直すかは、実機で触った感想をもらってから決める
- マップ選択の「Q・E で切り替え」など、一部の案内は、キーの名前のまま（◀ ▶ を直接触れば切り替えられる）
- 押しやすさ、ボタンの大きさと場所、動きの重さは、実機で触ってもらってから直す（作る側では、実機で確かめていない）

## 32. ゲームパッド（2026-10-09 追加）

パソコンにゲームパッドをつないで、ボタンかスティックを触ると、ゲームパッドで遊べる。設定で切り替える必要はない。キーボードとマウスは、今までどおり使える（マウスを動かすと、向きはまたカーソルのほうになる）。ボタンの名前は Xbox のもの。

### 戦闘・隠れ家
| ボタン | 動作 |
|---|---|
| 左スティック／十字キー | 移動 |
| 右スティック | 倒している間、その向きを向く。倒していない間は、オート（ロックオン。「26. 操作方法」）。設定の「操作方法」がマニュアルでも、ゲームパッドで操作している間はこうなる |
| X | 調べる。足元に装備が落ちているときは、バッグに入れる（身につけるのは、ポーズ画面の「装備」から） |
| Y | 修復キットを使う |
| B | 消耗品の切り替え（枠1から順に。選んでいる枠に、黄色い枠が付く） |
| A | 選んでいる消耗品を使う（向いている先を狙う）。最後のボスを倒したあとは「帰還する」 |
| RB | 攻撃（押している間） |
| LB | 特殊アクション |
| RT | ロックオンの切り替え |
| LT | ダッシュ回避 |
| ＋（メニュー） | ポーズ画面／隠れ家のメニュー |
| −（ビュー） | エリアの地図 |

### メニューなど
- **ポーズ画面・隠れ家のメニュー**：LB・RB でタブを切り替える。左スティック・十字キーで項目を選ぶ。A で決定、B か ＋ で閉じる・戻る。Y は、スキルツリーの「次の取れるマスへ」
- **タイトル・セーブ枠・マップ選択**：左スティック・十字キーで選ぶ。A で決定、B で戻る
- **会話**：A で進める。選択肢は、X が1つ目、Y が2つ目。＋ で飛ばす
- **レベルアップの3択**：左スティック・十字キーの左右で選び（黄色い枠が付く）、A で決定
- **リザルト**：A で「隠れ家に戻る」
- **倒し続けると、速く動く**：メニュー・タイトル・セーブ枠・マップ選択では、左スティックを倒し続けるか、十字キーを押し続けると、0.4秒たってから、0.06秒ごとに1つずつ動く（長い一覧を、速く送れる）。離すと止まる
- **「操作」タブ**：ゲームパッドで操作している間は、キーボードとマウスのときと同じ並びで、左にゲームパッドの図（ボタンを働きごとに色分け）、右にボタンの一覧（ボタンの操作、メニューの中での働き、武器ごとの攻撃と特殊。上下に動かせる）を出す

### まだやっていないこと
- マウスでしか触れない所（装備の付け替え、設定の値、スキルツリーの絞り込み、マップ選択の持ち越しの選択、名前の入力など）は、ゲームパッドだけでは操作できない
- 画面の案内（「E：扉を選ぶ」など）は、キーボードの言葉のまま
- ボタンの割り当ての変更、振動は、ない
